## 一、需求 → 现状映射（决策矩阵）

## 二、三层架构与落位

| 层 | mod | packageId | 职责 | ModsConfig 位次 |
|---|---|---|---|---|
| A 底座（复用，只读不改） | 边境拓展HSK | `NehsModsForDev.bordersoftherim` | 领土/边界/战争/附庸/单线承认度 | 现 184 |
| B 新建 | **边缘外政核心** | `local.hsk.edgepolitics` | 双线认可度、暗杀事件(好感/敌对驱动)、帝国从属编排、驱动外政定向任务 | 建议 **184–187** 区间（特性拓展在 187 后，压尾仍 hskfixpack→AITranslation→EndMod） |
| C 重构 | 任务大修HSK | `local.hsk.questoverhaul` | 任务等级/奖励/来源/属性四维度重构，读取 B 外政态 | 现 155 |

**数据流（单向依赖，避免成环）**：
`B 产生外政状态(双线认可度/tension/从属/ActiveWars) → C 任务来源/属性/奖励读取 → C 任务完成回报 → B/好感回写`。
好感一律走原版 `Faction.TryAffectGoodwillWith`/`SetRelationDirect`（与 BOTR 同路，零冲突）。
**线程模型**：决策核心可独立、一切执行写留主线程独占落 → 详见 [`外政核心_线程与事件决策模型.md`](./外政核心_线程与事件决策模型.md)。

**加载边规则**（AGENTS §2）：
- B 只 **patch** `WorldComponent_Territories.WorldComponentTick` 与 BOTR def → 唯一 `loadAfter` 加 `NehsModsForDev.bordersoftherim`。
- B/C 引用帝国/美狐/Kurin 等派系 **defName** 属"全量加载后统一解析"，**不加边**（照任务大修已删 `miho` 边的教训）。
- 新增每条 loadAfter 前跑 `_tmp/loadorder/find_cycle.py` + `check_order2.py` 双口径验无环。

## 三、外政系统骨架（Layer B，新建）

设计要点（详见附录 §1–§2、§4）：

1. **双线认可度**：`imperialStanding`/`freeStanding` 两条 0–100 + 各自承认方集，按"是否落所选宗主从属树"分轨（字段/阶梯详见附录 §1）。
2. **暗杀/谋杀（好感/敌对驱动）**：目标线认可过低 **或** BOTR `FactionBorderContact.tension` 超阈时解锁 ChoiceLetter；成败走原版 `SetRelationDirect`/健康 API，避开 BOTR 占的 `CheckDefeated`/`Quest.Accept`（附录 §2）。
3. **帝国从属编排**：三层组合 = 静态 `permanentEnemyToEveryoneExcept` + `GoodwillSituationDef`/`Meow` 破上限 + BOTR `TerritorialDependency`；宗主选 `Empire`（或 `Rakinia`/`MedievalKingdom`，附录 §4）。**白名单 HMC 死条目禁抄**。

| 维度 | 现状（八期） | 重构目标 | 落点 |

## 六、跨阶段铁律 / 风险

> **进度（09-02）**：P1 骨架/两暗杀队 def/P3a 金额系统给 已实装同步；详见 `任务与悬赏体系优化.md` §六。

- **不改 BOTR 私有子系统**，只经 public API 读、postfix 排 tick；不重复 patch `CanPlaceSettlement`/`SettlementSuitability`（本地 HSKPatch 已占）。
- **补丁**：Operation 级 `MayRequire` 已失效→一律 xpath 存在性门控；`1xx` 是首字符序陷阱，"最终层"用 >91 两位数编号；改补丁必过 `_tmp/patch_simulator.py`。
- **DLL**：声明式 `[HarmonyPatch]` 遇重载须显式参数类型；`GameComponent`/`WorldComponent` 子类 ctor 写 `public X(Game/World)`；Assemblies 目录禁遗留同名测试 DLL；改完清 MissileGirl XML 缓存。
- **性能**（§9）：外政/任务全部低频轮询（tick 取模），事件驱动优先，禁每 tick 遍历 map/派系/世界物。
- **文档**：每份 ≤10KB，超了外挂指针；`.md`+`.html` 成对；成果自验通过再登记导航 §二。
