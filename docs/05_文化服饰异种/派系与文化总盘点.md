## 鼠族HSK — 派系与文化总盘点

> **数据源**:`Mods/Unified.xml` 最终合并态(游戏导出,含全部已加载 mod 与补丁)。
> **口径**:1.6.4871 + Core_SK + RatkinRaceHSK + CE + Vile's MS + ResearchTreeSK 等全套。
> **规模**:具体派系 **77** 个(另有 ~17 个抽象基类不计入)、文化 **22** 个。生成日期 2026-08-28。
> **中文说明**:中文名/首领称谓/成员称呼/描述均取自游戏内**汉化包 DefInjected**(77 派系 + 22 文化全覆盖),缺汉化时回退 def 原生中文标签;括注的原生英文/韩文仅作对照。`defName` 为稳定主键。
