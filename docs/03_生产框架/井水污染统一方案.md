## 1. 现状盘点(反编译结论)

### 1.1 DBH 井水污染原生链(BadHygiene.dll)
- 井 = `WaterWellInlet`(浅井,`CompProperties_WaterInlet.Radius=7.9`)/ `DeepWaterWellInlet`(深井,Radius=13.7,`Deep=true`),comp `CompWaterInlet : CompBaseWell`。
- **每 1500 tick**(浅井)`SanitationUtil.PollutionInCell(map, GridArea, ref log, reportString:true)` 汇总井半径内:
  1. 卫生管网污水 `SewageFrom`(DBH 原生);
  2. **原版污染格** `map.pollutionGrid.grid[cell]` → **+10/格**(Biotech 污染地面);
  3. 原版毒雾 `GameCondition_ToxicFallout`(已持续 ≥120000 tick)→ **+50**;
  4. **可配置清单**: `DefExtensions.TerrainPollitionTypes` / `ThingPollutionTypes`,来源 = DBH 自有 def `DubsBadHygiene.PollutionDef["PollutionTypes"]` 的 `TerrainTypes`/`ThingTypes` 节点(`defName`+`toxicity`),解析用 `GetNamedSilentFail` → **缺失 def 静默跳过,纯 XML 补丁可安全扩展**。现有表已含 `Filth_OilSlick` 30(Rimefeller 油膜)、`Grave` 20、`RawSewage` 100 等。注意:同 def 只计一次(FirstOrDefault 去重,与数量无关)。
- 污染值对照阈值 `CompBaseWell.ContaminationThreshold=50`,界面显示"污染程度%"(`PollutionLevel` 键,DBH 汉化包已有)。
- `PollutionPct > 1` → 管网内首个非污染水箱 `CompWaterStorage.WaterQuality = Contaminated`(三档 Treated/Untreated/Contaminated)。
- 用具/饮用时 `SanitationUtil.ContaminationCheckWater(pawn, 水质)` → `Need_Hygiene.Contaminated()` + `GiveNastyGutBug`(DBH 疾病: 腹泻/痢疾/霍乱)。**这是 DBH 现有效果,保留**。
- 免疫口(DBH 原生,保留):深井 `Props.Deep` / 管网挂滤水器 `WaterTreatment`(`pipeNet.HasFilter`)→ `Pollution=0`。

### 1.2 原版污染效果统一基准(Assembly-CSharp 1.6)
- `ToxicUtility.DoPawnToxicDamage(pawn, factor)` = 原版毒性**统一入口**: `0.023 × (1−ToxicResistance) × (1−ToxicEnvironmentResistance) × factor → HealthUtility.AdjustSeverity(ToxicBuildup)`。毒雾/污染地形/毒气最终都走这里。
- ⇒ "效果统一成原版"= 井水致毒也调它,**自动吃双抗**(种族毒抗 + 装备/基因环境毒抗;污染统一阶段 B 的防护统一正好把防毒面具/呼吸面罩接进同一抗性栈)。
- 尸体瘴气 = 1.6 原版 `GasType.RotStink`(`map.gasGrid`,四通道 smoke/toxic/rotStink/deadlife,单格浓度 0~255),腐烂尸体自动散发;吸入另有原版 `RotStinkExposure`→肺腐病链(**不重复、不动**)。

### 1.3 四污染源载体与接入方式
| 源 | def/载体 | 接入 |
|---|---|---|
| 尸体瘴气 | `GasType.RotStink`(气体网格,无 def) | **DLL postfix**(DBH 不读气体网格) |
| 石化油泄漏 | Rimefeller `Filth_OilSlick`(油膜,已 30)/ `Filth_Oil`(油渍,未计) | 油渍走 **XML**;罐击毁布油膜=新 comp(二期可选) |

## 3. 深化:井水污染统一

### 3.1 统一属性(毒度量表,全部汇入井水污染池,阈值 50)
| 源 | 载体 | 毒度 | 方式 |
|---|---|---|---|
| 原版污染地面 / 毒雾 / 管网污水 | — | +10/格 / +50 / 原生 | DBH 原生,不动 |
| 尸体瘴气 | gasGrid RotStink | 井区平均浓度% × **25**(满浓度 25) | DLL |
| 石化油膜(泄漏) | `Filth_OilSlick` | 30(原表已有) | 不动 |
| 石化油渍(踩踏带出) | `Filth_Oil` | **15** | XML |
| 有毒垃圾(囤放) | `Wastepack` | **40** | XML |
| 核废料(囤放) | `NuclearWaste` | **60** | XML |
| 放射尘 | `RadioactiveDust` | **25** | XML |
| 核天灾(熔毁 fallout) | RadioactiveFallout/NuclearFallout | **+50**(对齐毒雾) | DLL |
- 梯度原则: 油渍(踩带)<垃圾<核废料;气体按浓度折算≤25;天灾一次≈毒雾。沿用 DBH"同 def 计一次"语义。
- XML 补丁 = 对 `DubsBadHygiene.PollutionDef[defName="PollutionTypes"]` 的 `ThingTypes` 顶层 Conditional+Sequence Add;每条 `<li>` 写 Def 级 `MayRequire`(Biotech/Rimatomics/Rimefeller),双保险(DBH 侧 GetNamedSilentFail 也会跳过)。PatchOperation 在 def 解析前执行,DBH `ResolvePollution()` 启动期才读表 → 时序成立。

### 3.2 统一效果(原版污染效果)
- 保留 DBH 原生: 污染水 → 卫生需求污染 + 肠胃病(腹泻/痢疾/霍乱)——"卫生"侧不变。
- **新增 DLL postfix** `SanitationUtil.ContaminationCheckWater`: 水质==Contaminated 时追加 `ToxicUtility.DoPawnToxicDamage(pawn, 3.0f)` ≈ 每次用/喝污染水等效毒雾露天暴露 3 个判定周期;**自动吃 ToxicResistance+ToxicEnvironmentResistance**,防毒面具/防护服/防辐射服全部生效。该函数仅用水/饮水事件触发,天然低频。
- 净化口不变: 滤水器 WaterTreatment / 深井 / 水箱排水重储。
- 井检视明细: `CompBaseWell.PolutionLog` 通道仍在,postfix 同步向 `ref string report` 追加"瘴气/放射天灾"两行,沿用 DBH 既有键风格(新键放工业大修 `Languages/ChineseSimplified/Keyed/`)。

### 3.3 实现件
1. `1.6/Patches/Patch_DBH_污染源统一.xml`(§3.1 表格全部 XML 条目)。

## 4. 兼容与边界
- **老存档**: Asphalt defName 不变,已产沥青/配方无缝;`AsphaltProducerComp` 类保留(旧 CrudeCracker 实例可能带该 comp);新补丁全部存在性门控,缺任一污染源 mod 不报错。
- **语义**: DBH 物品毒度与数量无关(原生去重)——"囤 1 块还是 500 块核废料都计 60"是 DBH 设计,文档如实标注;若日后要按数量加权需改 DBH 私有逻辑,本期不做。
- **不重复计伤**: 瘴气的原版吸入链(RotStinkExposure→肺腐)与井水毒ging相互独立,一个管"在井边闻",一个管"喝进去"。
- **性能**: 全部挂 DBH 原生 1500 tick/井 低频路径与用水事件,无新增每 tick 遍历(§9 铁律)。
