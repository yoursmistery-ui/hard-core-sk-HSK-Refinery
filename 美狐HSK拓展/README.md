Based on existing steam CE patch, merged into one with Miho mod.
All calibers replaced by HSK variants except mechanite psyshot.

Supported RimWorld versions: 1.5 and 1.6.

The 1.6 port includes the current Miho content, HSK/CE conversions for the new
weapons and pawns, adjusted raid combat power, corrected crafting recipes, and
conditional Odyssey support for unique weapons, the ship cannon and vacsuits.
Odyssey content is loaded only when the DLC is active.

The 1.6 HSK layer also restores the unused seasonal Santa Miho as a one-time
drop-pod event. Each year has a 60% roll during Decembary 10-15 until the event
fires; the uninjured Santa helper immediately joins the player, and the event
can never repeat in that save.
