# 房间统计 RoomStatDef（14 条）

按 `updatePriority` 降序计算：优先级 2（财富/空间/美观/清洁）→ 1（观感）→ 0（曲线派生的隐藏系数）。

### 观感 `Impressiveness`

**来源** 原版 Core ｜ **更新优先级** 1 ｜ **无房间时** 0 ｜ 显示项 ｜ `RoomStatWorker_Impressiveness`

**算法**：四个因子分别过 `GetFactor()`：`Wealth/1500`、`Beauty/3`、`Space/125`、`1 + min(Cleanliness,0)/2.5`。取 **平均值** 与 **最小值** 按 0.35 插值：结果 = Lerp(平均, 最小, 0.35)。若结果 > `Space因子×5`，再向该上限插值 0.75（空间不足会硬性拉低观感）。最后 ×100。

**曲线**：GetFactor：`|x|<1` 返回 x；`x>0` 返回 `1+ln(x)`；`x<0` 返回 `-1-ln(-x)`

**评级档位**：<20 糟透 / 20 沉闷 / 30 平庸 / 40 尚可 / 50 略为可观 / 65 颇为可观 / 85 非常可观 / 120 极其可观 / 170 难以置信 / 240 叹为观止


### 财富 `Wealth`

**来源** 原版 Core ｜ **更新优先级** 2 ｜ **无房间时** 0 ｜ 显示项 ｜ `RoomStatWorker_Wealth`

**算法**：Σ（建筑/植物的 `stackCount × MarketValue`）+ Σ（每格地板的市场价值）

**评级档位**：<500 贫寒 / 500 略贫 / 700 平庸 / 2000 略富 / 4000 富裕 / 10000 奢华 / 40000 非常奢华 / 100000 极其奢华 / 1000000 难以置信


### 空间 `Space`

**来源** 原版 Core ｜ **更新优先级** 2 ｜ **无房间时** 350 ｜ 显示项 ｜ `RoomStatWorker_Space`

**算法**：若 `PsychologicallyOutdoors` → 固定 **350**。否则逐格累加：**可站立 +1.4**、**仅可通行 +0.5**，上限 350。

**评级档位**：<12.5 拥挤 / 12.5 略挤 / 29 一般 / 55 略宽敞 / 70 相当宽敞 / 130 非常宽敞 / 349.5 极其宽敞


### 美观 `Beauty`

**来源** 原版 Core ｜ **更新优先级** 2 ｜ **无房间时** 0 ｜ 显示项 ｜ `RoomStatWorker_Beauty`

**算法**：Σ 各格 `BeautyUtility.CellBeauty` + 相邻（墙等）物件所在格的美化值（同格只算一次），再除以 `CellCountCurve(CellCount)`。

**曲线**：除数曲线：格数 0→20，40→40，100000→100000（小房间被 20 起步的除数摊薄，大房间接近 1:1）

**评级档位**：<-3.5 丑陋不堪 / -3.5 难看 / 0 中性 / 2.4 好看 / 5 美观 / 15 非常美观 / 50 极其美观 / 100 难以置信


### 清洁 `Cleanliness`

**来源** 原版 Core ｜ **更新优先级** 2 ｜ **无房间时** 0 ｜ 显示项 ｜ `RoomStatWorker_Cleanliness`

**算法**：Σ（建筑/物品/污物/植物的 `stackCount × Cleanliness`）+ Σ（每格地板清洁度），再 ÷ 房间格数。

**评级档位**：<-1.1 肮脏不堪 / -1.1 脏 / -0.4 略脏 / -0.05 干净 / 0.4 无菌


### 阅读加成 `ReadingBonus`

**来源** 原版 Core ｜ **更新优先级** 0 ｜ **无房间时** 1 ｜ 隐藏项 ｜ `RoomStatWorker_ReadingBonus`

**算法**：对每个 `Building_Bookcase` 累加其 `CellsFilledPercentage`，按"**满度消耗**"逐段换算：第 1 个满度单位 ×0.04，其后依次 ×0.02、×0.01、×0.005。返回 `1 + min(累计, 0.2)`，即最高 +20%。

**曲线**：递减系数表：[0.04, 0.02, 0.01, 0.005]，上限 0.2

**评级档位**：隐藏项，不显示评级


### 感染几率系数 `InfectionChanceFactor`

**来源** 原版 Core ｜ **更新优先级** 0 ｜ **无房间时** 1.0 ｜ 隐藏项 ｜ `RoomStatWorker_FromStatByCurve`

**算法**：输入 **Cleanliness** 过曲线求值。无房间时取 **1.0**。

**曲线**：(-5, 1.0) → (0, 0.5) → (1, 0.2)　注释：永远不会比"完全不治疗"更糟

**评级档位**：隐藏项

### 天窗覆盖 `SolarWeb-Stratum-SkylightPercentage`

**来源** Core_SK Stratum ｜ **更新优先级** — ｜ **无房间时** 0 ｜ 显示项 ｜ `SolarWeb.Stratum.Stats.SkylightPercentage`

**算法**：若心理户外或格数为 0 → 0。否则 Σ（天窗格 × `(1 - SkylightCoating 涂层不透明度)`）÷ 房间格数。

**评级档位**：0 无 / 0.1 轻微 / 0.5 显著 / 0.9 完整
