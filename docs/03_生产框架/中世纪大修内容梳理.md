### 1.2 木材链

- 原木 `DankPyon_RawWood`(原生木)/ `DankPyon_RawDarkWood`(暗木)→ 锯木架切 → 2× 原版 `WoodLog` / 2× `DankPyon_DarkWood`(暗木板,Woody,耐久防热更高)。
- **机制**: FilteringLists 的 SeperateWoodList 把原版砍树产物劫持为 RawWood,再经锯木架切回木板。
- 特殊: 远古木 `DankPyon_AncientWood`(Schrat 掉落,炼金素材,非 stuff)。

### 1.3 皮革/生皮链

- 生皮系统 **C# 自动生成**(无独立 XML): 屠宰每头动物按 尺寸(Tiny~Huge)× 类型(Hide/ThickHide/SoftPelt/HeavyPelt/Scale/Bird)生成 `DankPyon_Hide_*`。
- 鞣制: 生皮 + 鞣革液(木头或食物制)→ 鞣革架/鞣革桶 → 皮革。
- 新皮革(stuff Leathery): 生革(Rawhide 最弱)、Rox 皮(高防高保温阻燃)、狮鹫/恐狼/恐猪/鬣狗/巨魔皮、**顶级**: Daer 皮(防2.2/冷34)、Lindwurm 龙鳞(耐热34/HP2.5)、Rox 羊毛(冷30 顶级保温,Wools)。

### 1.4 布料/纤维链

- 亚麻秆 → 纺车 → `DankPyon_Linen` 亚麻布(Fabric);棉 → 纺车 → 原版 Cloth;羊毛 → 纺车 → Cloth;蚕 → 丝绸床 → `DankPyon_Silk` 丝绸(防热0.9/HP60 奢华)。

### 1.5 炼金素材(猎怪循环)

- 植物药: 思绪草 Mindwort / 罂粟 / 亚麻籽 / 毒蝇伞(药效0.60);草药萃取 HerbalExtract(医疗0.85)。
- 怪物部件(统一 DankPyon_AlchemyIngredients): Schrat 森林之心/远古木/辉光树脂;Unhold 巨骨/厚绒/巨皮/巨心;巨魔 蓝心/巨魔之心;Webknecht 蛛丝/毒腺/红背毒腺;Lindwurm 龙血/龙骨/龙鳞;食尸鬼 犄角;Alp 干瘪皮/石化尖叫/第三只眼;恐狼 肾上腺素腺。

### 1.6 食材/农产品

- 谷物链: 小麦 → 磨粉 → 面粉(副产麦秆饲料)。
- 调味: 甘蔗→糖、盐(深矿/矿井)、香料;蜂蜜/蜂蜡(养蜂场);羊奶/牛奶→奶酪(品质熟成);动物脂肪→脂油(蜡烛/肥皂)。
- 肉品保存: 生肉→干肉(干燥架)/烟熏肉(烟熏房)→ 包装口粮 MealRations / 素食 Macci。
- 蔬果: 番茄/苹果/柠檬/桑葚/卷心菜/胡萝卜/大蒜/洋葱/南瓜/扁豆/格里芬浆果;怪物蛋可食可孵化。

### 1.7 宝石/奢侈品

- 宝石(全部深矿脉、stuff DankPyon_Gems 可做建材): 黄水晶→琥珀→黑曜石→祖母绿→蓝宝石→红宝石(3.95→16.65 价值梯度)。
- 奢侈品(战利品可清洗): 银/金圣杯、碗、骷髅、骰子;废武器(可熔炼回收 2钢+5铁锭)、藏宝图 TornNote、职业技能书 treatise(15000 XP)。

### 1.8 新 stuff 类别(可直接做建材)

`DankPyon_Hide`(生皮)、`DankPyon_RawWood`(原木)、`DankPyon_Gems`(宝石)3 个新 StuffCategoryDef;大量复用原版类别: Metallic(铁锭)/ Woody(dark wood、骨)/ Fabric(亚麻、丝绸)/ Leathery(全部新皮革)/ Wools(rox 羊毛)。

## 3. 建筑与家具体系

**建筑分类**: 3 个自定义顶栏分类(RusticFurniture "Rustic Furn."、RusticStorage、RusticDecoration)+ 挂原版顶栏(Security/Temperature/Joy/Misc/Structure)+ 14 个设计器下拉组(饮料/抄写/蜡烛/锭堆/麻袋等)+ 11 个地板下拉组(同图案多材质合并)。

### 3.1 结构与墙

- 门: 乡村门/原木门/大门/加固原木门(多格)/石板门(开关极慢)+ 1×2 大型多格门系列(需相邻墙)。
- 墙: 原木墙(HP400 易燃)→ 栅栏(含射孔版)→ **都铎墙**(木2+黏土3,Beauty+3)→ **城堡墙**(石15,HP1000 不燃,**弱点: 炸药4倍/钝击2倍**)+射孔版。
- 柱/框架: 原木柱/皇家金柱/隔断柱(撑屋顶)。
- **无桥、无梯子、无楼梯**(定义全部注释停用,HSK 整合可作扩展点)。

### 3.2 储物(深度堆叠,非 DeepStorage)

- 机制: 原 LWM_DeepStorage 父类被注释,改用原版 ShelfBase + `maxItemsInCell=4`(4堆/格)。
- 箱子: 乡村箱/金属箱(铁锭20)/皇家箱(铁20+金10);衣橱。
- **资源专用储具**(每格4堆、防室外变质): 原木堆/木料堆/砖堆/六种锭堆/木桶系列(矿/煤/布/皮/组件/葡萄)/麻袋(面粉/麦/土豆/苹果)/板条箱(含骨头/Unhold/龙装饰款)/谷捆/粮堆。
- 货架: 通用+专用(药草/药/宝石/金银器/书/图纸/食物/锭);大货架 2×2 四堆(面包/谷物/肉/奶酪/酒)。
- 武器架(固定存武器)、橱柜(面包/奶酪/酒)、马车(2×2 储物)。
- **冰窖 DankPyon_IceCellar**(3×3 固定存冰块防融化,需 Stonecutting)。

### 3.3 温度与火源

- 冰柜(以冰块为燃料,被动制冷 -11热/s);柴堆/圆柴堆(80热/s 上限38°C,兼焚烧台+火焰冥想);柴炉(11热/s);壁炉(32热/s,兼做早期厨房+火焰冥想)。
- 照明兼加热: 火把/壁挂火把/油灯(焦油)/路灯/蜡烛(牛油/蜂蜡)/烛台/油灯;火盆(6.5热)。蜡烛需 CandleMaking 研究。

> 2026-08-27 新增。数据源: 本地副本 `...\3219596926\1.6\` 下。

### 16.1 矿井体系全貌(无独立"深矿井"建筑)

MO 中**没有**独立命名的"深矿井"建筑;用户语境里的"矿井+深矿井"实为同一座矿井 `DankPyon_MineShaft`(其配方即"深层竖井开采",深挖出矿)。相关建筑:

| defName | 类型 | 说明 |
|---|---|---|
| `DankPyon_MineShaft` | Building_WorkTable 3×3 | **主矿井**(配方式开采,ITab_Bills),需求 `DankPyon_Mining` 研究 + 铁锭60 + 基础组件10 + Woody 300 |
| `DankPyon_MiningSpot` | Building_WorkTable 1×1 | 挖掘点(慢速,0.5 倍,无成本),需求 `DankPyon_Mining` |
| `DankPyon_DiggingSpot` | Building_WorkTable 1×1 | 挖土点(黏土/泥土),terrainAffordance Diggable |
| `DankPyon_RuinedMineShaft` | 废墟装饰(地图生成) | 不可用,仅战利品 |

### 16.2 矿井配方(Recipes_MineShaft.xml)

全部配方 `recipeUsers=DankPyon_MineShaft`,workSpeedStat=MiningSpeed,workSkill=Mining,effectWorking=CutStone。

| 配方 defName | 产物 | 工时 | 备注 |
|---|---|---|---|
| `DankPyon_MakeStoneChunks_Coal` | DankPyon_Coal×25 | 2000 | — |
| `_Sandstone/_Granite/_Limestone/_Slate/_Marble` | 原版 Chunk×1 | 2250/2975/2700/2275/2100 | 5 种石材块 |
| `DankPyon_MakeSalt` / `_SaltBulk` | DankPyon_Salt×1/10 | 200/2000 | — |
| `DankPyon_MakeTar` / `_TarBulk` | DankPyon_Tar×1/5 | 700/3500 | 需研究 `DankPyon_Tar` |
| `DankPyon_MakeGunpowder` / `_Bulk` | DankPyon_Gunpowder×1/5 | 700/3500 | 需研究 `DankPyon_Gunpowder` |
| `DankPyon_MakeOre_IronOre` / `_Bulk` | DankPyon_IronOre×1/5 | 900/4500 | 铁矿石 |
| `DankPyon_MakeOre_SilverOre` / `_Bulk` | DankPyon_SilverOre×1/5 | 600/3000 | 银矿石 |

**暴击机制**(`MedievalOverhaul.RecipeExtension_Mine`): 每 600 tick 工时 1% 概率暴击出 6 宝石之一 + 金矿(其中 6 宝石为 DankPyon_Citrine/Amber/Onyx/Emerald/Sapphire/Ruby,DankPyon_GoldOre)。

**虫灾机制**(`MedievalOverhaul.CompProperties_CreatesInfestations_Mine`): 矿井开采可能触发虫灾(mtb 20 天/钻)。

### 16.3 依赖链(提取时必须处理)

- 研究: `DankPyon_Mining`(成本1000,前置 `DankPyon_Engineering`,MO tab)→ **HSK 整合需换挂 Mining 链**。
- 产物材料: 全部是 MO 自有 def(DankPyon_IronOre/Coal/Salt/Tar/Gunpowder/SilverOre)→ **HSK 环境需映射**(见 §16.4)。
- WorkGiver: `DankPyon_DoBillsMineshaft`(WorkGiver_DoBill,fixedBillGiverDefs 指向矿井)。
- **DLL 依赖**: 暴击扩展 + 虫灾 comp 均在 `MedievalOverhaul.dll`,提取到本 mod 后**必须移除或改写**(本 mod 无 MO DLL)。

### 16.4 HSK 出厂材料适配映射(2026-08-27 用户确认终版)

**核心**: 矿井=**无限产物**建筑(可无限设置 Bills 持续挖,非一次性矿脉),产物表与 Quarry/Minerals("菜市场")明确区分。

**最终产物(6 种)**:

| 序号 | 产物 | HSK 对应 def | 说明/归属 |
|---|---|---|---|
| ① | 煤 | `Coal`(原版)+大修版 | 保留 |
| ② | 磁铁矿 | Vile `Titanomagnetite`(Fe+Ti+V) | 走 Vile 炼钢链;与 Minerals 铁矿区分 |
| ③ | 盐 | `Salt`(原版) | 保留 |
| ④ | 粘土 | HSK `SoftClay`(Core_SK 软粘土) | 保留 |
| ⑤ | 铜矿 | HSK `Copper`(铜矿石,Vile 链→CopperBar) | 保留 |
| ⑥ | 宝石(6 种) | MO `DankPyon_Citrine/Amber/Onyx/Emerald/Sapphire/Ruby` | **留下**(财富/珠宝/Stuff 装饰材料) 经 Vile 链 |

**移除**: 火药(Gunpowder)、焦油(Tar)、银矿、金矿、铁矿石(MO 版)全部删——与 Minerals/菜市场区分。

> 宝石确认下: 6 种为 Stuff 可做建材+珠宝,价值梯度 3.95(黄水晶)→16.65(红宝石)。金矿(GoldOre)属暴击池,若并入则单独列;当前保留宝石、不保留金矿/银矿。

> 落地时按 AGENTS.md §4(汉化)、§6(研究台六档)、§8(二级菜单)与 CE 铁律逐项适配;科技节点独立命名,参考 Quarry 采矿机制。
