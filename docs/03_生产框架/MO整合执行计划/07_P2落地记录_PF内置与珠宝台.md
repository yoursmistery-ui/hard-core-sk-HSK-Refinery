## 五、必须记住的 UI 铁律(本轮新增)

## 六·补 宝石暴击与矿井虫灾(08-28 已补做)

**宝石暴击 = 自研,零 MO DLL**:`Source/MiningCritHSK.cs` → `MineCritProperties`(RecipeDef 扩展)+ Harmony postfix 挂在 `GenRecipe.MakeRecipeProducts`(显式给全 8 个参数类型,避开重载歧义)。概率按工时折算 `chance = critChance × (workAmount / workPerRoll)`,上限 35%,与 MO"每 600 工时 1%"同曲线;命中后掉 1~3 个宝石(池 = `RKGem_Citrine/Amber/Onyx/Emerald/Sapphire/Ruby`),可选弹信。扩展挂在采掘配方**基类** `RK_MineShaftBase` 上,14 条配方共用。只在产物生成这一事件点触发 → 无 tick、无轮询,符合 AGENTS §9。
