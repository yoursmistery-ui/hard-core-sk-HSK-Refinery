## 四、跨阶段公共约定

1. **前缀**: 一律 `Rustic_`(结构/家具,沿用已落地约定)、`RK_`(机制/派系向 def,如任务/站点/商队)、`RKGem_`(宝石 stuff)。禁止沿用 `DankPyon_`。
2. **材料映射主表**(MO → 本环境): `RawWood→Woody/WoodLog`、`Clay→SoftClay`、`BlocksClay→自烧砖(对标 TileCeramics)`、`Linen→Cloth`、`IronIngot→Iron`、`ComponentBasic→ComponentMedieval`、`Silk/Paper/Tar/Wax/Straw/Coal` 与 6 种宝石 **HSK 侧不存在**(仅 Jade、Straw/Coal/Tallow 存在) → P5 建宝石、P2 决定纸/丝主链。
3. **研究门禁**: 新增建筑一律挂 HSK 现有节点(ComplexFurniture/Stonecutting/Glassworking 等);**新增科研节点**才须按 AGENTS §6 补 `SK.AdvancedResearchExtension` 六档硬门槛。
4. **CE**: 本计划**不含武器/防具**,故唯一 CE 触点只有生物的武器/护甲适配(P4)与珠宝的 `WornBulk`(若需要)。
5. **汉化**: 内联中文 label/description(与 `Buildings_Rustic_*` 同法,100% 生效);界面串才走 DefInjected `<LanguageData>`。
6. **贴图**: 从 MO 的 `1.6/Textures` 按 def 的 texPath 拷进本 mod `Textures/`,保持相对路径不变(MO 原路径无 `DankPyon` 前缀目录,冲突风险低,拷完核对全环境重名)。
7. **验证**: 纯 Defs 改动 → ET.parse + 终态核对(下次启动读 `Unified.xml`);补丁改动 → `_tmp/patch_simulator.py`;DLL 改动 → `build.ps1` 重编译 + 清 MissileGirl XML 缓存。
8. **文档体量**: 遵守 AGENTS §1 单文件 ≤10KB 铁律,超出的明细外挂成分册,主文件留指针。
