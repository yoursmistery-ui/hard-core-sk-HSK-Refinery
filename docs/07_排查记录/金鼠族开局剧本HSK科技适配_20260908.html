现象与归因

两个剧本的 ScenPart_StartingResearch 沿用原版时代的选点，未按 HSK 科技树重新校准。HSK 下这些 defName 虽都存在，但档位/语义全变，造成双向错配：

  • 超发：SterileMaterials 在 HSK 已抬到 Spacer 档（900 点，前置 Plastic_floor_C4，HiTechResearchBench）。开局给了会经 FinishProject 递归连带解锁 塑料地板 C1→C4 + 石化线 Oil_Industry_C1/C2/C5 + Mining_C1 整条链。
  • 欠发：金鼠族核心科技一个没给——衣物I（OA_RK_Apparel_I，缝纫设施+常服）、武器I（OA_RK_Weapon_I，古典步枪）、医疗（OA_RK_Oberonia_Aurea_Research_C，青苏药物）开局全要自己从零研究 → "有配方没科技"，种族特色生产线开不了工。

证据链

  • 反编译 RimWorld.ScenPart_StartingResearch.PostGameStart → ResearchManager.FinishProject：递归完成全部前置（1.6 确认），故剧本每个节点都按"前置闭包"计强度。
  • 反编译 DirectXmlCrossRefLoader.WantedRefForList.TryResolve：列表型交叉引用解析失败静默跳过（非 null 入列）→ Rifles_C1 的悬空前置 Gunsmithing（Core_SK 源码引用但 def 已不存在）只产生一条启动期噪音，不会让开局递归炸掉。
  • 全 Mods 源码建研究表（613 节点）算闭包：现状剧本 31 节点 15275 点（Spacer 1 个）。
  • 基准：鼠族 TradeRoad 给 Ratkin_Apparel_B1+Electricity（闭包 6 节点 3100 点）；美狐 Miho_Start 给 7 项（闭包 20 节点 11450 点，含 Machining/BlowbackOperation/BasicMechtech 三个死引用——美狐侧遗留，另案）。
  • 派系层兜底：金鼠族玩家派系 startingResearchTags = RK_ResearchTag_MedievalBasic，自动授予鼠族基础锻造/缝纫/试做（ResearchUtility.ApplyPlayerStartingResearch，同样递归）。
  • BasicGravtech 为原版 Odyssey def，HSK DLC 模块仅重挂档（2500 点/前置 OrbitalTech），Navigate 保留它正确。
  • 起始物品全部存在（Gun_BoltActionRifle/Apparel_FlakVest/Synthread 为原版 def，HSK 未删；OA_RK 系物品在 mod 内），问题不在物品清单。

修法

并入既有剧本 def 文件（不新建 xml），两个剧本同改：

  • 删 4 个原版时代节点：CarpetMaking / SterileMaterials（Spacer 超发）/ NobleApparel / TreeSowing（地板/贵族/植树 filler，基准剧本均不给）。
  • 增 3 个金鼠族核心科技：OA_RK_Apparel_I + OA_RK_Weapon_I + OA_RK_Oberonia_Aurea_Research_C（医疗，前置已随农业线给，净增 1200 点）。
  • 留：OA_RK_Oberonia_Aurea_Research/_B（种族农业线）、Electricity（与鼠族基准一致）；Navigate 另留 BasicGravtech/BiofuelRefining。
