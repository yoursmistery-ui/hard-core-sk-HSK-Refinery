# P5 · 矿井采掘 + 宝石 stuff(方案拉出,可直接开工)

> 来源: `中世纪大修内容梳理.md` §16(方案已定稿)+ 本次 MO 实测。**这是用户唯一"§1 材料"要做的一项(宝石 6 档)+ 明确"已经想要做"的矿井**,范围小、映射清楚,建议与 P1 并行开一条独立支线。
> 铁律: 不引 MO DLL → 暴击与虫灾必须自研(或先不做);矿井=**无限产物**建筑(可无限设 Bills 持续挖),与 HSK `Quarry`/Minerals("菜市场")定位明确区分。

### 08-28 落地定稿(采掘配方重构 + 矿井地形门禁)

- **矿井地形门禁**: `RK_MineShaft` 与 `RK_MiningSpot` 一样, `terrainAffordanceNeeded` 从 `Heavy` 改为 **`SmoothableStone`** → 只能建在可打磨岩石地面(`Rough<岩种>Floor`)上。
- **强度统一**: 每种资源删除"单条 + 批量"两条, 合并为**单条 x5**(工时按旧批量档折算控强度): `RK_Mine_Coal`1000 / `RK_Mine_Iron`4500 / `RK_Mine_Copper`3500 / `RK_Mine_Salt`1000 / `RK_Mine_Clay`1000。
- **石材随地面岩种**: 5 条逐岩种配方合并为单条 `RK_Mine_Stone`(产物 x1)。运行时由 `BlueprintUnlockHSK.dll` 新增 postfix `Patch_MineStoneByTerrain` 读建筑所在格地形 `Rough<岩种>Floor` → 去 `Rough`/`Floor` 段拼 `Chunk<岩种>` 产出; 拼不出对应碎块(玄武岩/纯橄岩/伟晶岩/方解石岩等 Minerals 岩石无 `Chunk` def、火山岩、已采掘地面)回落 **`CrushedStone`**。配方挂 `MineStoneByTerrainProperties`(带继承来的宝石暴击 ext)。
- **采掘点改版**: 删煤, 改为 `RK_MineSpot_Salt`(盐x5)/`RK_MineSpot_Rubble`(碎石 `CrushedStone` x5)/`RK_MineSpot_Sand`(沙子 `SandResource` x5), 挂 `Mining_B1`, 速度 0.5×。
- DLL: `build.ps1` 补 `Unity.Mathematics.dll` 引用后 csc 零错重编译 → 双目录 `BlueprintUnlockHSK.dll` hash 一致。终态以游戏启动日志 + `Unified.xml` 复核。

## 三、宝石 stuff(§1 唯一要做项)

**实测**: HSK 侧现有宝石 stuff **只有 `Jade`**;Amber 仅作为 colorDef 存在,Citrine/Onyx/Emerald/Sapphire/Ruby 全缺。所以 6 档要自建,命名 `RKGem_*`:

| defName | 参考价值 | 备注 |
|---|---|---|
| `RKGem_Citrine` 黄水晶 | 3.95 | 最低档 |
| `RKGem_Amber` 琥珀 | 4.95 | |
| `RKGem_Onyx` 黑曜石 | 6.95 | |
| `RKGem_Emerald` 祖母绿 | 9.95 | |
| `RKGem_Sapphire` 蓝宝石 | 12.95 | |
| `RKGem_Ruby` 红宝石 | 16.65 | 最高档 |

- 需要一起建: `StuffCategoryDef`(可直接复用 MO 的 `DankPyon_Gems` 语义,改名 `RK_Gems`)→ 并把它加入相关建筑/家具的 `stuffCategories`,让 P3 的**宝石骷髅装饰、珠宝台产物、陶瓷砖**能用上。
- 每档 = `ThingDef`(资源类,`stuffProps.categories`、`statBases`、`marketValue`)+ 材质贴图(`Things/Resource/Gems/**`)。
- 用途闭环: 矿井暴击出 → 珠宝台(P2)做首饰 → 装饰(P3)做宝石骷髅 → 商人(P4 艺术赞助人)回收。
- **不做**金矿/银矿暴击(与定稿一致)。
