## 3 TFC 还能搬进来的（性价比排序，全纯 XML）

1. **热处理树（最推荐，零新 def）**：坩埚钢 → 三种淬火介质 → 复用现成 def 当产物：水淬 = `ToolSteel` 工具钢（硬而脆）、油淬 = `SpringSteel` 弹簧钢（韧弹）、空冷正火 = `CarbonSteel` 中碳钢（均衡）。一下拿到"选料 + 选介质"双决策，且把 Materials Science 那几个散钢名收编进阶梯。
2. **选矿碾磨**：贫矿 →（`StampMill`，`StampMillTech` 现成）碎矿 + 尾砂（=炉渣）→ 再进高炉。品位差异变成看得见、算得出的产渣量。
3. **工具头 + 木柄两段装配**（TFC 标志设计）：铸/锻出"镐头/斧头/撬棍头" → 与木柄组装成成品工具。正好接你已做的 STL 工具线。
4. **燃料分级门禁**：`TableFurnace` 的 `fuelFilter` 现在柴/煤/泥炭都能烧 = 等于没门禁，收紧到只 `Coke`/`Charcoal`（焦炭已有 `coke_process` @窑，链已通）。
5. **铁砧 + 焊剂门禁**：大件（炮管、板甲、管件）要求 `Anvil` 建筑 + `FluxPowder`；铁砧按"能直建就不进工作台"落成建筑。
6. **一次性陶模/失蜡模**：铸造产物必须消耗模子（可用次数有限），绑 `Ceramics_A1 → B1` 线，TFC 手感最强的一条。

明确不搬：岩层矿脉世界生成、锻造实时小戏、随时间磨损耐久、"点火后不可中断"的高炉（前两项无对应系统，后两项要 DLL）。
