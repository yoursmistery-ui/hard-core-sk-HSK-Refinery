## 4. 需要重启 / 注意的事项

1. **含 DLL 更新**(Core_SK.dll、HSK_MoreInfo.dll、TechAdvancing.dll),更新后必须**完全退出游戏再重启**,不能只退回主菜单。
2. 8/23 日志提及的"HSK More Info 配方产量说明"功能仍需在设置中开启后才生效。
3. 本次不强制新建存档;Roos Painting 等贴图翻新对旧存档即时生效。
4. 若使用覆盖式更新过 Vile 皮革补丁,旧 `Animals_leatherType.xml` 已不存在,勿再手动放回(会导致与新 `_Anomaly`/`_Biotech`/`_Normal` 文件并存)。
