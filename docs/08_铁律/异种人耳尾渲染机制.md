# 异种人耳/尾贴图渲染机制(HSK 整合)

> 来源: AGENTS.md §3 问题1+问题2 修复(2026-08-26)。改异种人(RGE 特殊耳/尾)渲染、补贴图时先读本节,避免"加了对但不显示"。

## 1. 两套独立渲染管线
- **机制A = Biotech `renderNodeProperties`**(基因自带): `RK_Gene_LargeEars`/`RK_Gene_ThinTail` 用,渲染 `Things/Ratkin/Body/RK_Texture_EarLeft`,**初鼠种走这里,可靠**。
- **机制B = HAR `universalBodyAddons` 的 `Gene For` 映射**(`Patches/RKGE/RKEarsTailPatch.xml`): 渲染 `Textures/Body/SQ_EarLeft` 等,**RGE 特殊异种基因(松鼠/仓鼠等)走这里**。

## 2. 坑1(HT): 机制B 在 HSK 运行时失效
- 多 mod 往 `RK_Race_Setting/universalBodyAddons` Add 时叠加不可靠(实测金鼠族 `OAGene_*` 耳朵 GeneFor 在 Unified.xml 丢失),且配置虽正确(Gene For→ConditionGene 序列化正常)但特殊耳不渲染。
- **修复: 改走机制A** —— `Patches/RKGE/RKEarsTail_MechanismA.xml` 给 8 耳基因+5 尾基因 Add `renderNodeProperties`(复刻 `RK_Gene_LargeEars`/`RK_Gene_ThinTail`,texPath=`Body/` 相对本 mod Textures/,linkedBodyPartsGroup=RK_LeftEar/RK_RightEar/RK_Tail,实际靠 parentTagDef=Head/Body 定位不依赖部位组)。

## 3. 坑2: 贴图方向补全
- 机制A 渲染的耳朵贴图需 `_east/_north/_south/_west` 四方向;特殊异种耳贴图原缺 `_west`(机制B 下无此需),改走机制A后**必须补全**。
- 耳朵 `_west` = `_east` 水平镜像(已验证 `RK_Texture_EarLeft_west` 与 east 镜像平均每通道差值 1.4)。
- 尾巴无 `_west` 是正常(原版 `RK_Texture_Tail` 也只有 e/n/s)。

## 4. 坑3: 基因分组显示
- 异种人基因显示在"系谱基因"栏是 RimWorld 正确机制(异种人基因=可遗传端基因 xendogene);"异种基因"栏只有后天不可遗传基因。
- 原版 RGE 用自定义 `GeneCategoryDef`(RatkinGene/RatkinEarsGene/RatkinTailGene)在编辑器里分组;本 mod 曾注释掉,已恢复(`Defs/RKGE/GeneDefs_Ratkin.xml` 定义 + displayCategory 引用 + 汉化 `RkGeneCategory.xml` 就位)。

## 5. 类名可见性
- 补丁引用跨 mod 类(如 `PawnRenderNodeProperties_EarHideByApparelTag` 在 RatkinRaceHSK 的 NewRatkin.dll)只要目标 mod 加载即全局解析;但依赖该类的补丁**必须 `loadAfter` 该 mod**(本 mod About.xml 已 loadAfter `Solaris.RatkinRaceMod`)。
