0 · 结论

全游戏没有独立"任务板/悬赏委托"mod。任务统一走原版 QuestScriptDef 框架,由四类投递通道 + 结局线送达;原版 + 4 个 DLC(Core/Royalty/Ideology/Biotech/Odyssey,Anomaly 未启用)是骨架,10+ 个 mod/框架填自定义任务。本文用双视图组织:§1 按"任务从哪来(机制)"建树,§2 按"哪个派系给的(派系树)"交叉重排。

~140原版+DLC 脚本(Data/ 打包)
0QuestDef(导出工具不导此型)
⚠ 三个易错:Vortex Kingfisher 名字像钓鱼任务,实为纯性能补丁(无 XML)——排除;event mod ≠ 任务 mod(Cybranian 18 事件里只 2 个是任务);只 grep QuestScriptDef 会漏掉 GoExplore/Minerals(纯 IncidentDef 世界据点)与 OA 框架/金鼠族/边境(DLL 生成)。

3 · 刷新 / 门槛 —— 框架级统一规则

随机委托能否出现由 NaturalRandomQuestChooser.GetNaturalRandomSelectionWeight 判定(反编译实锤):

  • 进池前提:rootSelectionWeight>0(0=走事件/DLL/设施专属通道)。
  • 三重门槛:points≥rootMinPoints · 开档天数≥rootEarliestDay · 进度分≥rootMinProgressScore。
  • 同任务冷却 minRefireDays;最近5任务 RecentRandomQuests 逐级降权(不连刷同款)。
  • 一次性/全局唯一:QuestPart_Unique tag restriction=UniqueSuccess/UniqueAvailable;并发上限 maxSpawnCount。
  • 事件通道另一套门槛(B/D 类):baseChance·minRefireDays·earliestDay·minPopulation+人口曲线(见 GoExplore/Cybranian/Minerals)。
  • 好感/敌对门控:金鼠族系普遍要 OberoniaAurea 非敌对。

4.6 MO = Medieval Overhaul 未启用(探秘桌设计原型)

MO 不在 ModsConfig.xml,其任务不直接进游戏;列此因它是 HSK工业科研大修"探秘桌"的设计原型,并便日后对照。

MO 自带废墟/邪教委托链,由自家 QuestFinder(信鸽站BirdPost/信使台MessengerPost/探险家工作台,链接件 1/5/9 解锁 1~3 级)生成:DankPyon_OpportunitySite_SmallRuin/MediumRuin/Snake_BigRuin(废墟搜刮,可伴守卫陷阱)、Cultists_1/2/3Tier(邪教讨伐,档位越高奖励越高)、AlpEclipse(月蚀事件)。
移植现状:工业科研大修 Buildings_RK_QuestChain.xml 复刻了探秘链设施但零 MO DLL(自研 CompQuestFinderHSK,点击消耗"残页情报 RK_TornNote");产出的是原版 ItemStash/BanditCamp(600/1200/2200 点),未搬 MO 的废墟/邪教任务本体。

5 · 坑与口诀

  • Unified XML Export 只导 QuestScriptDef,不导 QuestDef(实测 176/0);原版奖励表在 Data/ 打包内。
  • 盘点不能只 grep QuestScriptDef:必须并查 IncidentDef(GiveQuest/Misc)+ 各框架 DLL——否则漏 GoExplore、Minerals、OA框架/金鼠族/边境的真实任务量。
  • event mod ≠ 任务 mod:判真任务看 worker 是否 IncidentWorker_GiveQuest 或 category 是否 GiveQuest,别凭 mod 名(Cybranian 18 只 2 真)。
  • Kingfisher 是性能补丁,非钓鱼任务 mod。
  • Anomaly 未启用(仅 knownExpansions)→ 无异常/恐怖任务线。
  • 选 Rotty Milden 叙事者 → 委托·访客·商队密度显著上升。
  • 金鼠族硬绑 OberoniaAurea(交恶整批失效),风雪线还要"风雪遗孤"剧本。
  • 金鼠族/边境/Ratkin/OA框架真逻辑在 DLL,XML 只文案+门控或空壳 root → 改数值多半不在 XML;要精确到每条委托须反编译框架 DLL。
