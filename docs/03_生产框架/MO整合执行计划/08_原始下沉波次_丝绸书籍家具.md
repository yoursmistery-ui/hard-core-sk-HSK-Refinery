## 一、丝绸 → Vile 布料产业 TIER 2.5(HSK工业科研大修)
- `Things_RK_TextilePaper.xml` `RK_Silk` 重写为 Vile 布料字段结构: `BedRestEffectiveness=1.3`(休息效率冠绝诸布)、`Insulation_Cold=22 / Heat=18`(双面隔热)、`Beauty 系数=2.5`、`MarketValue=15`、`Flammability=1.8`(易燃为唯一短板)、`categories=Fabric`、`techLevel=Medieval`。定位=超越原始时代的超强天然布, 介于中世纪有机布(TIER2)与工业合成布(TIER3)之间。
- 生产线从 `Fabrication`(工业·需电) 下移到新建中世纪节点 `RK_Sericulture`(蚕桑缫丝, MedievalBase, 前置 Apparel_B1=提供纺织机 TableLoom, Apparel_SK 坐标 5,39): 蚕匾架 `RK_SilkwormTray` + `RK_RaiseSilkworms` + `RK_WeaveSilk`(挂 TableLoom+TailoringSpeed) + PF 自动丝绸床 `Rustic_SilkBed` 四处改挂。养蚕/缫丝/织绸无需电力即可在中世纪成型。

## 二、书写 → 原始时代(书籍拓展HSK)
