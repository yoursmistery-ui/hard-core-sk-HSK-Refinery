## A. 土地污染统一

### A.1 原版基准: 有毒物品怎么污染土地(反编译 Biotech Wastepack)
`Wastepack`(Data\Biotech\...\Items_Resource_Manufactured.xml)三件套 = 原版唯一标准链:
1. `CompProperties_Dissolution` — `dissolutionAfterDays=8`,室内 ×0.5 减速、雨中 ×2 加速,溶解进度随暴露累积,满后物品销毁;
2. `CompProperties_DissolutionEffectPollution` — 每次溶解 `cellsToPollutePerDissolution=6` 铺**原版污染格** + 世界瓦片 `tilePollutionPerDissolution=0.0005`(水瓦片 ×8);
3. `CompProperties_GasOnDamage`(ToxGas ×堆叠数)— 受损/燃烧时放毒气(附注,非土地侧)。
溶解→污染格后,效果全部原版: 毒土 overlay、`ToxicUtility.PawnToxicTickInterval` 行走中毒ging、植被枯死。**统一 = 后续有毒物品全部挂同款 comp,不发明新机制。**

### A.2 统一动作表
| 物品 | 现状 | 动作 |

| 废料包 Wastepack | 原生基准(8天/6格) | 不动 |

- `Item_RadioactiveThing.Tick()` 要求 tickerType=Normal(已满足),加 comp 不冲突;辐射线(Rimatomics 私有)与溶解线(原版)双轨并存: **辐射伤人、溶解污地**。
- 老存档: 已在场物品实例按 def 重建 comps,补 comp 无害。
- 与井水侧关系: 双轨互补——物品**溶解**→土地(污染格);物品**囤放井边**→井水(DBH ThingTypes 清单,毒度表见主方案 §3.1)。互不替代。

## B. 删除石油泄漏事件(整个事件连内容)

### B.1 事件解剖(Rimefeller.dll)
- `IncidentDef OilSpill`(`Rimefeller_SK\Defs\Storyteller\Incidents_Map_Misc.xml`): baseChance 0.3、minRefireDays 30、目标 Map_PlayerHome、`workerClass=Rimefeller.IncidentWorker_OilSpill`。
- 触发条件(CanFireNowSub): 地图油管网有储罐且 `TotalOil > 200`。
- 执行(TryExecuteWorker): 随机挑油管网里一根管 → 拉走 min(100, TotalOil) 油 → **摧毁该管** → `OilSpillGrid.AddAt(爆点)` 铺油膜 + 标准信件("一段管道破裂…")。
- 油膜网格 `OilSpillGrid` 为 Rimefeller 私有系统: `DoCellSteadyEffects` 在有油格生成 `Filth_OilSlick`(thingClass `Rimefeller.OilSpill`)、超容量向邻格蔓延、杀植物;「清理油膜」指定(`Designator_CleanOil`)SetAt(0) 清除。

### B.2 删除动作
- 工业大修新增补丁(建议 `1.6/Patches/Patch_Rimefeller_删石油泄漏事件.xml`):
  顶层 `PatchOperationConditional`(xpath=`Defs/IncidentDef[defName="OilSpill"]` 存在性)→ match=`PatchOperationRemove`(同 xpath)。
- 事件 def 移除后,worker 类(`IncidentWorker_OilSpill`)在 DLL 中成死代码——**Rimefeller 本体零改动**(铁律),事件从叙事器杂项池消失、永不触发。旧存档无残留问题(事件 def 不入存档)。
- **保留的三条非事件泄漏路径**(与"井水会被石油泄漏污染"需求一致,不属于"事件"):
  1. 抽油机 BrokenDown 损坏期间向邻格周期漏油(`AddAt(CapacityTicksPerDay*120)`);
  2. 管道/储罐被击毁时按存量漏油(`Kicker()`/破坏路径);
  3. 「清理油膜」指定与清油工作链(清出来的后果才接我们的井水污染)。
- 已核: Core_SK / HSK修复整合 / 工业大修 / 污染统一 的 XML **无**对 `IncidentDef OilSpill` 的引用;AI 汉化包里 OilSpill 条目成死键,无害(可选顺手清理)。

## C. 污染闭环统一(污染 ⇄ 有毒垃圾)

> 目标: 沥青损毁→污染→清理→收集成废料包,并把"大多数污染"统一进这条链——**污染被捆绑到有毒垃圾上**,一切废物终态走原版消纳。

### C.1 原版闭环已内置(反编译实锤,清理侧零开发)
`WorkGiver_ClearPollution`(玩家画「清除污染区」驱动,Biotech 门控)+ `JobDriver_ClearPollution`:
- 每次工作 5600(GeneralLaborSpeed)清 **6 格**污染(`PollutionCellsToClearPerJob=6`),清完 `GenSpawn.Spawn(ThingDefOf.Wastepack)` 在旁边**刷 1 个有毒垃圾**;
- 守恒闭环: 1 废料包溶解 → 污染 6 格;清 6 格 → 回收 1 废料包。
- ⇒ **"污染清理→收集成有毒垃圾"原版已实现,不写任何清理侧代码**。统一整合 = 把更多污染源接进污染格,闭环自动成立。

### C.2 沥青损毁 → 污染(本篇新增 DLL 小 comp)
- **不能**给沥青套 `CompDissolution` 对: 它有按天计时溶解(室内也半速、只有冷冻/分解器内停),那是"废料必须冷冻"的专属语义——套上等于室内沥青库存慢慢化成毒土,破坏"沥青=材料"定位。
- 新 comp `CompProperties_PolluteOnDestroy / CompPolluteOnDestroy`(Source 并入 `BlueprintUnlockHSK.dll`,C#5 兼容):
  - `PostPreApplyDamage`: 伤害 ≥ 余 HP(烧毁/砸毁/露天烂掉等一切伤害性销毁,Deterioration 同算)→ 铺污染;
  - `PostDestroy(mode)`: 非友好拆除兜底(复用 `GasHazards.FriendlyRemoval` 判定);
  - 铺法 = 原版公共 API `PollutionUtility.GrowPollutionAt(pos, map, stackCount × 6)`(与 `CompDissolutionEffect_Pollution` 同一 API;`ModLister.CheckBiotech` 不在场直接短路);
  - XML: Asphalt def 的 comps 加一行(工业大修自有 def,无需门控)。库内/搬运中/容器内不触发。
- 大堆损毁平衡: stackLimit=100 的整堆损毁理论铺 600 格——comp 加每事件上限常量(建议 60 格),施工时定值。

### C.3 覆盖面盘点(大多数污染怎么进这套)
| 来源 | 进污染格方式 | 状态 |
|---|---|---|
| 废料包(溶解/损毁/乱扔) | 原生 CompDissolution 对 | ✅ 原生 |
| 毒气发生器 ToxifierGenerator(机械集群建筑) | 原生持续污染周边 | ✅ 原生 |
| 核废料 / 放射熔渣 | §A.2 补 CompDissolution 对(8天/件,冷冻/分解器停;商队乱扔污世界瓦片) | 本方案 |
| 沥青(损毁) | §C.2 仅损毁触发 | 本方案 |
| 油膜 | Rimefeller 私有 OilSpillGrid | 例外(二期可选桥接) |
| 毒雾/尸体瘴气/核天灾 | 空气层 | 例外(不入土,by design) |
- 清理出口对上表**所有**污染格统一生效(产废料包),无需逐源适配——这就是"大多数污染统一"的落点。

### C.4 统一整合后的玩家闭环
产生(乱扔/损毁/事故/机械集群)→ **污染格**(毒土,行走中毒ging、植被枯死)→ 画清除区清理 → **收集废料包** → 消纳五选: ①冷冻储存 ②废料分解器销毁 ③污树吸收 ④发射/倾倒异种派系(善意链原生) ⑤(迁移件)核废料→废料包转换后同口消纳。
- 废料包 = 土地污染的"容器态",土地污染 = 废料包的"散落态",清理 = 装回容器——污染与有毒垃圾正式捆绑。
- 三层联动回顾: 土(本篇)+ 水(DBH ThingTypes: 废料包 40/核废料 60/油渍 15,**沥青可补 10**,主方案 §3.1)+ 气 RotStink(主方案 §3.2 postfix)。
