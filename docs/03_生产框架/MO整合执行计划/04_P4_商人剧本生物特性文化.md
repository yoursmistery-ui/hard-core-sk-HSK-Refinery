# P4 · 商人 / 剧本 / 生物 / 特性·Hediff·文化 / 书籍阅读

> 用户拍板: 商人 8 类**必加**;剧本**稍微加**;生物**挑几个独特的、适配 Vile 材料体系**;§11 心情/特性/Hediff/文化**融合 HSK 查缺补漏**,**文化风格(老世界人/沙漠)要**;§10 书籍与研究是**核心板块,针对性添加/复制/优化**。
> 好消息: 这一块**几乎全部纯 XML 可做**(MO 侧无自有类),只有任务/扫描链在 P1。

## 三、生物(挑独特性,适配 Vile 材料)

实测: MO 全部生物除 Mimic(用 `VEF.AnimalBehaviours.Pawn_SwallowWhole`,VEF 在场可用)外**都是原版 Animal 类**;`AdditionalButcherProducts` 是 MO DefModExtension → 丢弃,屠宰产物改走原版 `butcherYield` + 我们的掉落补丁。

| 候选 | 独特性 | 机制 | 产物映射(Vile/HSK) |
|---|---|---|---|
| 狮鹫 `Griffon` | 高(产蛋 10 天 + 驼兽) | 原版 EggLayer + 驮运 | 皮→Vile 皮革档;蛋→原版 `EggUnfertilized` |
| Rox | 高(产羊毛 160/15 天 + 奶 10/天 + 驼兽) | 原版 Shearable + Milkable | 毛→HSK 羊毛;奶→原版 `Milk` |
| Daer | 高(北地稀有路过 + 巨鹿角) | 原版,配 P1 巨兽事件 | 皮→Vile 高档皮 |
| 恐猪 / 恐狼 / 鬣狗 | 中 | 原版 | 皮→Vile 皮革档 |
| 大眼镜蛇 / 巨蟒 | 中(产蛋 + 毒咬) | 原版;毒咬走 CE/原版 hediff | 蛇肉→昆虫肉/肉;皮→Vile |
| 汉普夏猪 / Ravelder 牛 | 低(家畜) | 原版 FarmGroup | 与 Vile's Sow Farm 重叠 → **建议不做** |
| 怪物组(Schrat/巨魔/Unhold/蛛网怪/Lindwurm/Alp/食尸鬼/哥雷姆) | 极高但**全靠 DLL**(沉睡/分裂/再生/整吞/酸血) | — | 建议只搬 1–2 个"退化版"(去掉特殊机制,保留外观+掉落),或砍 |
| 变形怪 Mimic | 高(伪装箱子,和 P1 Lootable 绝配) | VEF 类可用 | **推荐**: 放进 P1 的藏身处/废墟池,做"会咬人的宝箱" |

- 必做适配: 每个生物 `tools` 转 `CombatExtended.ToolCE`(armorPenetration 按力量外推)、`statBases` 补 CE 甲值、`raceProps` 保留;掉落物一律映射 Vile/HSK 现有材料,**不新建 MO 皮类**。

## 四、§11 心情 / 特性 / Hediff / 文化

- **特性**(纯 XML,零 DLL): `DankPyon_Fighter`(射击+2、受伤-10%、崩溃阈值-0.9)/`DankPyon_Veteran`(射击+6、受伤-30%、移速+0.3)。环境已有 161 个特性,含功能重叠的 `Brawler`/`Nimble`/`Tough`/`deadshot`/`ShootingAccuracy` 与 Core_SK `Reaver`。**做法**: 改名(`RK_Warrior`/`RK_Veteran`)、调值去重(把与现有特性完全重复的条目砍掉,保留"打包型"超级特性),权重 0.2/0.1 保留。
- **文化**: `OldWorlder`/`Desert` 是纯原版 `CultureDef`,**无新 memes/precepts**,只加 `styleItemTags` + `thingStyleCategoryDef`(StyleDef 需一起搬)。Core_SK 已有 `Rustican`/`Knighthood`/`Sophian`/`Corunan`。用户明确要 → 做法: 新增 `RK_Culture_OldWorlder`/`RK_Culture_Desert` 两个**风格向文化**(不碰 memes),并把它们的 `styleItemTags` 接进我们已有的**服饰分区/文化换装体系**(`docs/05_文化服饰异种/服饰分区盘点.csv` + 42/43/44 号补丁),这样"玩家可在自定义文化里选到"——符合用户"可感知层优先"的一贯要求。
- **Hediff**: 可搬(纯 XML)= `DankPyon_Ate*` 食物心情系(原版 `HediffWithComps` + `SeverityPerDay`)/`Intoxication`(原版 `HediffGiver_Random`,但 §9 不做则失去来源)/`Painless`;必须砍(依赖 `HediffComp_*` DLL)= `LindwurmAcid`/`Daze`/`NightmareDamage`/`AlpSleep`。
- **品质心情/食物记忆 thought**: 纯 XML,但触发物(奶酪/葡萄酒/派)属 §9 与 §1 食材链 → 用户不做 §9 → **建议只搬 3–4 条挂在现有 HSK 食物上的"精致用餐"thought**,或整块随 §9 缓做。

## 六、验收与顺序

- 顺序: 商人(1 天,纯 XML,立刻改善蓝图书获取)→ 特性 + 文化 + Tale(纯 XML)→ 剧本前两本 → 生物精选(每只都要过 CE 适配)→ 佣兵团剧本(等 P1 城堡布局)。
- 每批验收: `Player.log` 无新错误 → 游戏内商人能刷出/交易/回购 → 特性在建号时能抽到 → 文化在 ideo 自定义里可选到 → 生物能生成、信息卡不报 "no support for Combat Extended"。
