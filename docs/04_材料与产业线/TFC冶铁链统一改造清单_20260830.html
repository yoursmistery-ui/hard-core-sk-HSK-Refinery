  • CastBar 成员：-CastIron +PigIron，41 条铸造配方改吃生铁（铸件本就是生铁水浇模，反而更对）
Step 2 炉渣产出 RecipeDef 原生多产物
  • 高炉 +炉渣×25｜炼铁炉 +炉渣×8｜搅炼精炼炉 +炉渣×10；贫矿路线单位产渣更多（品位=可见的渣量）

Step 3 炉渣下游闭环

3 TFC 还能搬进来的 全纯 XML

  1. 热处理树（最推荐，零新 def）：坩埚钢 → 水淬=ToolSteel（硬脆）／油淬=SpringSteel（韧弹）／空冷正火=CarbonSteel（均衡）。白得"选料+选介质"双决策，顺带把 Materials Science 那几个散钢名收编进阶梯
  2. 选矿碾磨：贫矿 →（StampMill，StampMillTech 现成）碎矿 + 尾砂(炉渣) → 再进高炉
  3. 工具头 + 木柄两段装配：铸/锻"镐头·斧头·撬棍头" + 木柄 → 成品工具，接你已有的 STL 工具线
  4. 燃料分级门禁：TableFurnace 的 fuelFilter 现在柴/煤/泥炭通吃 = 没门禁，收紧到只 Coke/Charcoal（焦炭链 coke_process 已通）
  5. 铁砧 + 焊剂门禁：大件（炮管/板甲/管件）要求 Anvil + FluxPowder；铁砧按"能直建就不进工作台"落成建筑
  6. 一次性陶模/失蜡模：铸造产物消耗模子（次数有限），绑 Ceramics_A1→B1，TFC 手感最强

明确不搬：岩层矿脉世界生成、锻造实时小戏、随时间磨损耐久、"点火后不可中断"的高炉。
