1 一句话结论

"槽里存金属液"用 float 池做不出"所有金属"；用"可带 stuff 的舀包/坩埚"能做，而且顺手把配方数从 形状×金属 压回 形状×2。

RimWorld 的 stuff（材料）挂在实物 Thing 上。数值池只能记"多少升"，记不了"这是什么金属"——要保留金属种类就得按金属分槽（青铜池、钢池、乌兹池…）槽数直接爆。只要"金属液"是实物，它的 .stuff 天然携带金属身份并沿链条自动传递：

熔炉   金属锭/矿石 ×N      → 舀包[stuff=青铜]        ← 一条配方吃任意金属
浇筑   舀包[stuff] + 模具   → 工具头[stuff] + 炉渣    ← 一条配方服务所有金属
装配   工具头[stuff] + 木板 → 成品工具[stuff]

配方数 = 形状数 × 2，与金属种数无关——这就是"一套配方配合海量模具"的解法。

2 两槽容器的两条实现路

A 纯 XML 推荐先做B DLL 真池 可选后置
金属液 / 种类RK_Met_Ladle 舀包（stuffable 实物，可堆可搬、显示金属色，stuff 零额外 def 携带种类）CompMoltenPool 双 float 池 + 两条 FillableBar；但池记不了金属种类 → 按金属分槽则爆炸，或丢属性
废料已实装的炉渣实物 + 渣池（限定 filter 存储建筑）池内渣值，满则拨闸停产
成本只写 XML，走既有补丁流程改 Source/PetroInfraHSK.cs（NeedsWater/GasPort 同类低频组件可仿）、重编译、性能铁律限低频

"进度条"差异：A 靠检视面板库存 + 渣堆实物（原生观感），B 能在地图上画两条条。若要池的手感，B 可叠在 A 之上——舀包仍承载 stuff，池只做容量与积压显示。别一上来做 B。

3 让 stuff 真的生效的前置（已核实）

  • TFJ_Tool_Hoe 等 STL 工具 def 当前没有 <stuffCategories>，所以 Vile 的 Cast_* 虽吃 cat:CastBar，铸出来的锄头仍是"无材料"的同一把锄头
  • 但它的贴图是 CutoutComplex 且有 Hoe_m.png 颜色遮罩 → 补一行 <stuffCategories> 就白拿"青铜锄 vs 钢锄"的颜色与价值/近战差
  • 边界：stuff 影响 MarketValue／Mass／近战 power／护甲；不影响 STL 工作效率（砍树速度在 modExtension 里与 stuff 无关）。要让高级金属"更好用"只有两条：按档拆工具头 def（def 膨胀），或接受"高级金属=更贵更硬的武器、效率相同"。建议后者，差异落在武器/护甲侧

4 模具三档（TFC 本身分档，正好当科技阶梯）

档材质制作工位复用可浇金属
原始打制石模石匠台 Stonecutting一次性，浇完即碎铜、锡、青铜（低熔点）
陶烧制粘土模陶工台 Ceramics_A1一次性铁、钢
铁金属型（铁模）铸造厂 Metallurgy_B4可反复用全部，含高熔点

"可反复用"的纯 XML 合法写法：浇筑配方消耗 1 个铁模、产物里再给回 1 个铁模——净消耗为零，无随机。"石模浇不了高熔点金属"用不同配方挂不同模具 filter 实现，静态可预期。

5 配方配合体系：CSV 驱动生成器

不手写几百条配方。唯一真源是一张表 _tmp/met_line_data/molds.csv → _tmp/met_line_gen.py 产 XML。每行描述一个形状：形状键/中文名/贴图名、有哪些档模具、最终成品 def（可空=新建）、装配段额外料（柄/焊剂）、每件吃多少金属与产多少渣、各段研究档与工位。完整列定义见 md §5。

生成器产 _tmp/met_line_check.py 期望清单：defName 唯一性、引用完整性、不越级。改数值改表，不改 XML；新增一个形状=加一行。模具/工具头/成品靠 stuff 染色，不需要为每种金属画图。

  1. P0 前置：封 Steel 捷径（《统一改造清单》Step4，手锻台 MakeSteelBars_Hand 出钢锭）——不封，整套新流程被一条原始档配方绕过；同时给要走的工具/武器补 <stuffCategories>
  2. P1 熔汤实体化：RK_Met_Ladle + 熔炉配方「任意 *Bar/矿石×N → 舀包 + 炉渣」+ 坩埚架（直建存储，按"能直建就不进工作台"）
  3. P2 浇筑改造：已实装 5 套模具链，"吃 cat:CastBar"改成"吃舀包"，产物由铸件毛坯改名工具头并带 stuff

  6. P5 可选：DLL 双池容器（真进度条）

7 风险与边界

  1. 改动面：环境 1759 条配方、88 项金属、本 mod 147 件装备。"所有金属都走熔汤"会把装备/组件/弹药一起卷进来 → 建议只让"工具头/武器头/铸件"这一类走新流程，其余照旧吃锭
  2. CastIron 教训：改 CastBar 成员牵动 41 条铸造配方；熔汤化后要重定义其角色（退化为"可直接浇的金属锭"集合，工具头另立 RK_Met_Heads 分类）
  3. Kiln 雷：Kiln 被 Core_SK 声明为 UniversalFermenterSK.ThingDef_UF，普通 RecipeDef 挂上去刷告警——新配方别往窑上挂，用陶工台/铸造厂
  4. ResearchTreeSK 与存档：每条新配方显式 researchPrerequisite、同一配方不挂两台（防 duplicate unlocked defs/越级）；按项目铁律不为旧存档做兼容，改坏直接开新档。细则见 md §7
