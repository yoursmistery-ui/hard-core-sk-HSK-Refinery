## 1. 抠图算法 v2（最终方案）

泛洪填充在 JPEG 纸张纹理 / 网格线 / 黑边框上**必失败**，改用 scipy 方案：

```python
# 1. 四角 patch 取中位数当背景色 → 全图色距二值化
bg = np.median(corners, axis=0)
fg = np.sqrt(((rgb - bg) ** 2).sum(2)) > tol

# 2. 开运算去细网格线/噪点
fg = ndimage.binary_opening(fg, iterations=2~3)

# 3. 填洞（浅色罐体+深色描边时内部会变背景，靠这步救回）
fg = ndimage.binary_fill_holes(fg)

# 4. 连通域：取最大域 + 收容中心落在主体 bbox 外扩12% 内、面积≥4% 的次级域
lab, n = ndimage.label(fg)
areas = ndimage.sum(fg, lab, range(1, n + 1))
big = int(np.argmax(areas)) + 1
# 次级域收容判定：面积 ≥ 最大域 4% 且 中心在主体 bbox 外扩 12% 内

# 5. 等比例缩放入画布
#    建筑：bottom_align=True（贴底）；物品：False（居中）
```

### 调参规律

| 情况 | 处理 |
|---|---|
| 深底深构件（天然气罐支腿被当背景吃掉） | tol 降到 **28** |
| 浅色罐体轮廓被 opening 打断 → 填洞失效 | tol 降到 **30** + `open_iter=1` |
| 白底网格线 | `open_iter=3` |
| 物品取"最左单件"却抓到大堆 | 面积阈值降到 **3%**（单件常 < 最大堆的 15%） |
| 纸张纹理背景（发电机图） | tol 提到 **50**，配合填洞 |

## 2. 踩过的坑（按代价排序）

### ① `split_proj` 的 `n` 取错维度 —— 卡了最久
投影向量长度必须是 `mask.sum(axis=axis).shape[0]`，**不是** `mask.shape[axis]`。
取错时只扫到 2/3 宽度，双视角图被判成一整块 → 发电机切分失败、assert 报错。

### ② 无端面视角时别硬凑侧视图
- 石油脑曾用「Vertical Down」立式罐当 east → 用户判错
- 氨气曾用「RIGHT SIDE VIEW」侧视当 east → 用户判错

**教训**：宁可让用户补素材或从正面视图裁圆头合成，也不要拿不相干的视角顶替。

### ③ dict 键名不一致
`layout.items()` 键是 `south/west/north/east` 全称，遍历时写成 `for d in "swne"`（单字母）→ KeyError。

### ④ 美狐高炉文件名是全称
`MihoShaftFurnace_north.PNG`（不是 `MihoShaftFurnace_n.PNG`）。

### ⑤ alpha 通道分析对 JPG 源图无效
源图多为 JPG 或不带透明的 PNG，`a > 30` 得到全图不透明，**必须用 RGB 色距分析**。

### 生成预览拼版
```python
from PIL import Image, ImageDraw
import glob, os
base = r"C:/Personal/Project/ratkin-patch/_tmp/petro_out"
files = sorted(glob.glob(base + "/**/*.png", recursive=True))
cols, cell = 6, 240
rows = (len(files) + cols - 1) // cols
sheet = Image.new("RGB", (cols*cell, rows*(cell+18)), (200,205,210))
d = ImageDraw.Draw(sheet)
for i, f in enumerate(files):
    im = Image.open(f).convert("RGBA")
    bg = Image.new("RGBA", im.size, (110,120,130,255))   # 灰底衬托透明区
    bg.alpha_composite(im); bg = bg.convert("RGB")
    bg.thumbnail((cell-8, cell-8))
    x, y = (i%cols)*cell, (i//cols)*(cell+18)
    sheet.paste(bg, (x+4, y+4))
    d.text((x+4, y+cell-6), os.path.basename(f)[:40], fill=(0,0,0))
sheet.save(r"_tmp/petro_out_preview.png")
```
