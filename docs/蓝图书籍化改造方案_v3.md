## 三、原版书籍机制调研结论(反编译 Assembly-CSharp 1.6,已验证)

### 3.1 书籍本体
- `BookBase`(抽象 ThingDef): `thingClass=Book`(Verse.Book),`thingCategories=[Books]`,`stackLimit=1`,`tradeNeverStack`,`inspectorTabs=[ITab_Book]`,自带 `CompQuality`。
- `CompProperties_Book`(RimWorld): 字段 `nameMaker`/`descriptionMaker`/`ageYearsRange`/`openGraphic`(Graphic_Multi)/`verticalGraphic`/`doers`(List<BookOutcomeProperties>)。
- 书架: 原版 `Bookcase`(2×1,10 本)/`BookcaseSmall`(1×1,5 本),基类 `BookcaseBase`(`thingClass=Building_Bookcase`,`storageGroupTag=Bookcase`,`maxItemsInCell=5`,`fixedStorageSettings.filter.categories=[Books]`,`ITab_ContentsBooks`,`PlaceWorker_DrawLinesToResearchTablesInRoom`)。
- **只要新书 `thingCategories=[Books]` 即可自动进原版书架**;书架上的书给房间 `RoomReadingBonus`(阅读/研究/娱乐加成)。

### 3.2 阅读链路(JobDriver_Reading,反编译确认)
```
JobDriver_Reading.MakeNewToils():
  PrepareToReadBook(取书/搬书/找座位)
  → ReadBook(duration)  // duration = job.playerForced ? 5000 : job.def.joyDuration
      tickIntervalAction:
        readingBonus = BookUtility.GetReadingBonus(pawn)
        Book.OnBookReadTick(pawn, delta, readingBonus)   // ← 每阅读 tick 派发给全部 doer.OnReadingTick
        pawn.skills.Learn(SkillDefOf.Intellectual, 0.1f*delta)  // 阅读本身加智力
        JoyUtility.JoyTickCheckEnd(..., Book.JoyFactor * readingBonus)
```
> ⚠️ 原版阅读是 **joy 活动**(joy.gain),与 D6"算科研工作"冲突。**执行时须自写 JobDriver**(见 §四.2),不能直接复用 JobDriver_Reading。

### 3.3 Doer 接口(反编译,写自定义 doer 的依据)
```csharp
public abstract class ReadingOutcomeDoer {           // Verse/RimWorld 顶层 doer
    protected ReadingOutcomeProperties props;
    public ThingWithComps Parent;                    // Initialize 时赋值
    public CompReadable Readable;
    public virtual void Initialize(ThingWithComps parent, ReadingOutcomeProperties props);
    public virtual void PostMake();
    public virtual void OnReadingTick(Pawn reader, float factor);   // 每阅读 tick
    public virtual void PostExposeData();
}
public abstract class BookOutcomeDoer : ReadingOutcomeDoer {     // 书籍专用 doer
    public BookOutcomeProperties Props;  public Book Book;  public QualityCategory Quality;
    public abstract bool DoesProvidesOutcome(Pawn reader);
    public virtual void OnBookGenerated(Pawn author = null);
    public virtual string GetBenefitsString(Pawn reader = null);
    public virtual void Reset();
    public virtual IEnumerable<Gizmo> GetGizmos();  // 等
}
public abstract class BookOutcomeProperties : ReadingOutcomeProperties {
    public BookOutcomeProperties() {}  public BookOutcomeProperties(Type doerClass);
}
```
- 参考实现: `BookOutcomeDoerGainSkillExp`(用 `OnReadingTick` 每 tick Learn;`PostExposeData` 存 Dictionary)。
- 原版 `BookOutcomeProperties_GainResearch` 的 doerClass=`ReadingOutcomeDoerGainResearch`(内部 `values` 字典按 tick 加科研值)——**本项目不用它**(D4 禁中间科研值)。

**新增**:
1. **`BlueprintBookProperties : BookOutcomeProperties`** —— XML 挂载入口,`DoerClass => typeof(BlueprintBookDoer)`。
2. **`BlueprintBookDoer : BookOutcomeDoer`** —— 核心 doer:
   - `OnBookGenerated`: 无操作(系列语义固定,不随机)。
   - `DoesProvidesOutcome`: `return !tracker.IsRead(parent.def.defName)`(已读的书不再提供效果 → 阅读列表里自动不再排队;**这也是"第二次读无效果"的实现点**)。
   - **完成触发**: 在自定义 JobDriver 完成时调用(见下),而非 OnReadingTick 累积。
   - `GetBenefitsString`: 显示"研读后解锁 <科技名> 进度 (x/N)"。
   - `PostExposeData`: 不需要(状态在 WorldComponent,天然存档)。
3. **`JobDriver_StudyBlueprint`(自写 JobDriver,D6)** —— "研读"工作:
   - JobDef 新增 `RK_StudyBlueprint`,`workType=Research`(科研工作,不吃 joy),`joyDuration` 不适用;时长 = `BaseTicks(tier) / speedFactor`。
   - **耗时公式(D7)**: `baseMinutes = 1 + tier`(即 tier1=2, tier2=3, tier3=4, tier4=5, tier5=6 分钟);`baseTicks = baseMinutes * 60 * (60000f/3600f)` → 即 1 游戏分钟 ≈ 41.67 ticks,`baseTicks = round(baseMinutes * 41.67f)`(tier1≈83 ticks)。注意这个数值很小(2 游戏分钟),若实际测试体感过快,备选方案: 按现实分钟×(1000/60) ticks 或直接用 ticks 常量表 `{83,125,167,208,250}` 并做成 mod 扩展字段可调。**执行时先用公式,游戏内实测后调**。
   - **速度因子**: `speed = 0.5f + pawn.skills.GetSkill(SkillDefOf.Intellectual).Level * 0.02f`(智力加成,20 级→+40%)+ `pawn.GetStatValue(StatDefOf.ResearchSpeed)`(科研速度加成)。`实际ticks = baseTicks / speed`(下限钳制 ≥30 ticks)。
   - Toil 流程: 取书→走到座位/书桌(复用找椅逻辑或简化为原地)→ Wait(实际ticks,每 tick 面向书本,可加 `pawn.skills.Learn(Intellectual, ...)` 与研究经验)→ 完成时 `tracker.MarkRead` + 检查集齐 `TryUnlock`(消息提示)+ `RecordTale` 可选。
   - WorkGiver: `WorkGiver_StudyBlueprint`(Scanner 判定: 可达、未禁、`DoesProvidesOutcome=true` 的蓝图书;优先书架旁)。归 Research 工作类型 → 小人"研究"优先级下自动执行。
4. **消息**: 首次读完 → "已研读《xxx》(系列 x/N)";集齐 → "科技已解锁: xxx(系列 N/N 集齐,可开始研究)"(NeutralEvent/PositiveEvent)。
