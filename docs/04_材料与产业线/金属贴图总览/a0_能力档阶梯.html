判定法:拿材料的 stuffProps/categories 去反查全库所有可选材质的成品(家具/建筑/服饰/武器/器械,共 1926 件), 得到该材料的"可做成品集合";再看这个集合能不能完全覆盖基准材料(塑料 448 件 / 低碳钢 941 件 / 塑钢 986 件)的集合。 完全覆盖钢 = 代钢级,覆盖塑钢 = 超钢级,只比塑料多出重机电 = 强化工程级, 和塑料一个样 = 塑料级,只做装饰件 = 装饰专用级,没有 stuffProps = 不可塑形(材质清单里根本不出现)。 另有 贵重品·不作材质一档:HSK 用 Extracted/Metals/PRS 装宝石·化石·未炼金银·翡翠,用 Metallic/RARBar 装提纯金属与焊料, 这些本来就不是拿去打装备的(材质覆盖 0~2 件),故从阶梯里摘出单列,免得和"材料不行"混为一谈。例外:翡翠石质覆盖 299 件,仍留在 装饰专用级。 这是集合包含判定,不是打分,所以"代钢级"= 钢能选的地方它全能选,可直接当代用。
