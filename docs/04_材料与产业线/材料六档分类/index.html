石化系家族怎么分(你说这块不熟,按 HSK/Vile 实际材料给的口径)

  • F3 塑料与聚合物 — 热塑/工程塑料(Plastic 类):通用塑料做壳体·管道·容器,工程塑料(ABS/PC/PVC/PP)在 HSK 里同时挂 StrongMetallic 等金属类,所以能替代金属出装备。
  • F4 合成纤维与织物 — HF 类:凯夫拉/尼龙/超高分子量/合成线,软质防具主力,不吃金属类。
  • F5 硅酸盐·玻璃 与 F6 硅酸盐·陶瓷 — 严格说不属"石化"而是硅酸盐工业(原料是砂/长石/高岭土,靠高温窑炉,和电解 furnace 一路),所以它们落电力工业(前期),只有军规陶瓷/透明铝这类才升到太空档。
  • 石化真正的下游是聚合物链:原油→三烯三苯→单体→塑料/纤维/橡胶/树脂;橡胶与树脂在本环境是配方原料(无 stuffProps),归 F2 类"仅原料"处理。
  • F7 宝石·珠宝料 — 走 RK_Gems,只做珠宝装饰,不参与金属类,所以"可打武装"为 0。
