# 全量漏译排查与补译_20260827

> 范围: `RimWorld\Mods`(含 workshop 定位) + `Data` 的简体中文加载链。工具链: `_tmp/transl_scan/`(scan7 + build_library + classify2 + apply_B_C + verify_zh + gaps2)。

## 一、扫描方法论(两条关键修正)

1. **加载根必须复刻游戏回退规则**。`ModContentPack.InitLoadFolders`(反编译):有 `LoadFolders.xml` 且命中版本节 → 只按声明加载(不加载根目录);**没有** `LoadFolders.xml` → 自动加载 `<root>/<版本号>` + `Common` + `<root>`。
   旧扫描漏了回退分支,导致 `1.6HSK核心汉化`(无 LoadFolders)整个 `1.6/Languages` 被误判为"未翻译",虚报 ~150 条。
2. **判"已译"不能看缓存值**。`Unified.xml`(缓存与 Mods 根那份)都在**翻译注入之前**导出,只有少数被 mod 直接改写的 def 显中文。唯一可靠依据是"中文语言根里是否存在该键"。
