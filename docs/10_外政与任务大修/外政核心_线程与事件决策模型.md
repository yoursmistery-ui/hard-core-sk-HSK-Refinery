# 外政/事件决策核心 · 线程模型与落位铁律

> 立档 2026-09-02。性质：**设计方案，未实现**。承接 [`外政与任务大修重构_架构设计方案.md`](./外政与任务大修重构_架构设计方案.md) §二 数据流、[`外政数据结构与挂钩点附录.md`](./外政数据结构与挂钩点附录.md) §0/§1。回答"外政/派系交互/事件能否丢到第二线程跑"。

## 一、边界：什么能搬，什么永远留主线程

| 子系统 | 能否离主线程 | 原因 | 正确做法 |
|---|---|---|---|
| 外政**派生数据**（双线认可度/附庸关系/边界图/战争解算/暗杀冷却） | ✅ 可后台 | 原版不读这些，是你自己的数 | 纯数据快照上跑，结果回灌 |
| 原版 `Faction.goodwill` / 关系 Kind | ❌ 主线程权威 | 全游戏**数百处同步读**（贸易定价/任务/商队到达/盟友派援/外交UI/CE·HSK·BOTR 自研）；`TryAffectGoodwillWith` 连带翻 Kind+发信+触发袭击（皆 UI/主线程） | 留主线程；核心只产出"该 +/- 多少"当命令 |
| 贸易（定价→搬运→`Dialog_Trade`） | ❌ 最难搬 | 谈完要真实搬/销毁/堆叠 `Thing` 并开 UI，全主线程独占 | 仅"算价"纯数学可离线，但相对风险不值得 |
| 事件/Incident **执行**（`IncidentWorker.TryExecute` 选落点/生 pawn/发信） | ❌ 执行主线程 | 触碰 map/room/tile/PawnGenerator/LetterStack | **可离线的是"决定+计时+外政专属事件"**，执行仍回主线程 |
| 渲染 / UI / 存档收集 | ❌ Unity 主线程 | — | — |

硬约束一句：RimWorld/Unity **活游戏状态单线程**；连官方存档都是"主线程先收集成 XML、后台线程绝不碰活对象"——反证活状态不能跨线程读写。

## 二、目标模型：独立"外政/事件决策核心" + 命令总线

- 核心拥有：自己的**状态镜像**（外政数据）+ 排程器 + 决策逻辑，产出**命令 `IntentCmd`**（入 outbox 队列）。
- **主线程是唯一写入者**：好感/贸易/发信/袭击/起任务/渲染，全在这一侧 safe point **drain 队列后应用**。
- 方向单向：核心算意图 → 主线程执行。**主线程永不反向"问"核心要好感**——`Faction.goodwill` 本就在主线程手里，核心要读就吃快照。
- 事件流：核心 tick 判"该出暗杀/勒索/开战/定向任务了" → 入队 → 主线程 `IncidentWorker.TryExecute` / `QuestUtility.CreateQuest` / `Find.LetterStack` 落地。

```
// 决策核心（WorldComponent_EdgePolitics 或后台 Thread 皆可）
Queue<IntentCmd> outbox;                 // 核心 push（可跨线程入队）
// 主线程某 WorldComponent.ComponentTick safe point：
foreach (var c in Drain(outbox)) ApplyOnMainThread(c);
//   ApplyOnMainThread: Faction.TryAffectGoodwillWith / SetRelationDirect / CreateQuest / Letter / RaidEnemy
```

## 三、两档实现

**① 决策核心 + 时间片（主线程，第一版默认）**
- `WorldComponent_EdgePolitics` 自己的低频 tick；每 tick 只处理 N 个派系、每帧限时预算摊平尖峰；outbox 同帧内直接应用（仍在主线程，零竞态）。
- 与 BOTR `%60==17` 的 `WorldComponentTick` 共存：加**薄 postfix** 排在 BOTR 领土刷新之后，读最新 `ActiveWars`/`FactionBorderContact.tension`（附录 §0）。**不改它私有 `Tick*System`**。
- 满足"独立一颗核心、事件跑→要出了→通知主线程触发"的全部诉求，只是这核心跑主线程时间片。

**② 图重算后台线程（可选升级，仅 profiling 证有帧峰才上）**
- 只把**纯数学**（边界洪水填充 / Dijkstra、战争结果解算）丢后台，吃**不可变快照**（int/float 与只读 DefOf；**不得引用活 `Faction`/`Thing` 实例**）。
- 存读档 / 暂停 / World 未就绪 → **冻结线程**（在 `WorldComponentUpdate(fromLoad:true)` 处 gate）；解算结果回主线程 safe point 应用。
- 快照允许一帧陈旧（外政是慢变量），但**绝不允许后台线程直接写回真状态**。

## 四、铁律与验收

- 好感 / 一切世界写**永不离开主线程**（附录 §1：统一走原版 `Faction.TryAffectGoodwillWith`/`SetRelationDirect`，与 BOTR 同路零冲突）。
- 后台线程代码里出现任何 `Find.World`/`Faction`/`Thing`/`Dialog`/活 def 实例的**写** → 直接判 bug。
- 性能铁律（AGENTS §9）：低频轮询 + 提前短路 + 缓存；写 DLL 自查——Tick 内禁遍历/反射/LINQ 全量/频繁字符串构造。
- 验收：静态扫线程边界（核心方法无活对象写）；跑 `_tmp/patch_simulator.py`（若涉补丁）；**默认不上②**，真测出帧峰再把"图重算"单独抽后台，其余保持①。
