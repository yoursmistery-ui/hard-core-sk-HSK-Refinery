Bug 1 · 火焰偏到建筑下方 尺寸溢出

根因（反编译 Graphic_Flicker.DrawWorker + CompFireOverlay）：火焰位置 = DrawPos(TrueCenter) + 建筑自身 DrawOffsetForRot + FireOverlay offset。 south 朝向 drawOffsetSouth=(0,-1,0) 被火焰继承，故火焰中心本就落在炉膛口——位置没错。 真问题是昨天补的 fireSize=1.4 过大，quad 以中心铺满，下半截垂到基座/地面以下 → 看着"火在建筑下方"。
验证：PIL 前视比例合成图（地板格+footprint 黄框）对比，1.4 溢出、0.8~0.9 贴合。
修法：fireSize 1.4 → 0.9，补 offset=(0,0.1,0)。电动版无明火，不动。

Bug 2 · 小人卡在原地无法动 疑似 PF OnGUI · 另一任务处理

新线索：日志出现每帧 OnGUI 异常（ProcessorFramework 的 JIT MissingFieldException），此类异常打断输入处理，玩家侧即表现"小人卡在原地无法动"——很可能是真因，而非寻路/通行性。已派熟悉 PF DLL 的独立任务排查，本任务不碰 PF / 小人移动，避免撞车。
误诊改动已回退：曾按"移植把 Building_Heater 写成 Impassable"把两版壁炉 passability→PassThroughOnly+pathCost40+fill→0.4；经新线索判定为误诊，已全部回退，两版恢复 Impassable/fill 1.0/无 pathCost。
教训 遇"小人卡住"先查 Player.log 的 GUI 异常再查寻路/堵路，别先动 def。
