## 1. 一句话定位

MO 的"阅读"= **原版 `CompProperties_Book` 体系 + `RequiredSchematic` modExtension 门禁**,而非独立 DLL(仅 `BookWithAuthor`/`CompProperties_DefinableBook`/`RecipeWorker_MakeSkillBook`/`BookOutcomeProperties_GainResearchDefinable` 四个 MO 专属类)。核心是三种书: **传说书 Tale(娱乐)/ 专著 Treatise(技能训练)/ 图纸 Schematic(研究门禁)**。

> ⚠️ 与 HSK工业科研大修现状差异: 本环境已有的「科技蓝图」(BlueprintUnlockHSK DLL)是**蓝图物品→使用加科研值→集齐解锁**的一套;MO 是**书/图纸物件→放书架→满足 RequiredSchematic 才能开始研究**的另—套。两套**机制互斥,不可混用**,整合需二选一(见 §6)。

## 3. 图纸门禁机制(`RequiredSchematic`)

### 3.1 门禁扩展

挂在 `ResearchProjectDef` 的 `<modExtensions>` 下:

```xml
<ResearchProjectDef>
    <defName>DankPyon_Crossbow</defName>
    ...
    <modExtensions>
        <li Class="MedievalOverhaul.RequiredSchematic">
            <schematicDef>DankPyon_Schematic_Crossbow</schematicDef>
        </li>
    </modExtensions>
</ResearchProjectDef>
```

**效果**: 玩家必须先持有并阅读对应图纸书(Schematic),该研究才可开始;未满足则 `CanStartNow=false`。

### 3.2 门控研究清单(14 个,来自 ResearchProjects_Misc.xml)

Crossbow / HeavyCrossbow / RepeaterBallista / Plasteel / Tar / Gunpowder / WarBow / MilitaryPolearms / NoblePolearms / MilitaryMaces / NobleMaces / MilitaryBlades / IntermediateCooking / AdvancedCooking。

## 5. 整合 HSK 的关键差异与决策点

### 5.1 纸(Paper)在 HSK 环境不存在

- MO 专著/造纸依赖 `DankPyon_Paper`(造纸压机造)。**HSK 无 Paper/羊皮纸体系**(查材料总览与全 Mods 均无)。整合专著/书时需:
  1. 要么补一条 HSK 造纸链(`DankPyon_Paper` 自建);
  2. 要么专著改用 HSK 既有材料(如 `RK_CanJuan` 或直接跳过)。

### 5.2 `RequiredSchematic` 依赖 MO DLL

- `MedievalOverhaul.RequiredSchematic` / `BookWithAuthor` / `CompProperties_DefinableBook` / `BookOutcomeProperties_GainResearchDefinable` / `RecipeWorker_MakeSkillBook` 全部在 `MedievalOverhaul.dll`。
- **整合到本 mod(无 MO DLL)无法直接引用**,需: 用 HSK工业科研大修已有的 `BlueprintUnlockHSK` 机制(蓝图物品)替代,或自写 DLL 类。

### 5.3 与 HSK工业科研大修"科技蓝图"的关系

- HSK工业科研大修已实现**蓝图门控**(BlueprintTargetExtension + CompUseEffect_Blueprint,蓝图→加科研值→集齐解锁),覆盖 tier1~5。
- MO 的图纸书是**另一种实现**(书放书架 + RequiredSchematic 硬门槛)。
- **两套并存会重复门控/冲突**。整合建议: 把 MO 要纳入的 14 门控研究**转成 HSK工业科研大修的蓝图门控**(新增 16 张蓝图书),而非引入 MO 的 RequiredSchematic 体系。MO 的 Tale/Treatise(娱乐/技能书)则改用原版 Book 体系(无 MO DLL),作为纯阅读内容整合。

### 5.4 研究台六档(AGENTS.md §6)

若新增研究节点(如矿井/阅读相关),须按时代挂 `requiredResearchBuilding` + SK `AdvancedResearchExtension.requiredResearchBuildings` 硬门槛。

### 5.5 汉化

- MO 自带简中 DefInjected 覆盖书籍/研究;但 `ResearchProjects_Misc.xml` 有 3 处 WIP 英文残留。
- 整合进本 mod 需补 DefInjected `<LanguageData>`(根节点 `<LanguageData>`,defName 作节点名)。

## 6. 采纳建议(供确认)

用户想"把阅读相关内容一起整合过来",结合现有 `HSK工业科研大修` 蓝图体系,推荐:

1. **采纳**: MO 的三种书(传说书 / 专著 / 蓝图-图纸书),转成 HSK 体系。
   - 传说书 Tale → 纯娱乐书(原版 Book,无需 MO DLL)。
   - 专著 Treatise → 技能训练书(原版 Book + 自写/复用对技能经验的效果;HSK 无 Paper 则换材料)。
   - 图纸书 Schematic → **并入 HSKindustrial 蓝图体系**,新增 `Blueprint_*` 物品(复用 BlueprintUnlockHSK),门禁语义=MO 的 RequiredSchematic。
2. **不采纳**: MO 的 `RequiredSchematic` 硬门槛 + `BookWithAuthor` 等 MO DLL 类(避免引入 MO DLL 依赖)。
3. **设施**: 研究书架(小/大/皇家)+ 抄写台 + 讲台 → 可作本 mod 建筑整合,研究书架用原版 CompProperties_Facility 加速。
4. **阅读心情**: `ReadInLibrary` 图书馆心情 → 复用原版房间心情,可选整合。

> 具体"哪些书/哪些图纸对应谁解锁"待用户确认后落地;落地遵循 AGENTS.md §3(补丁)、§4(汉化)、§6(研究台)、§8(二级菜单)。
