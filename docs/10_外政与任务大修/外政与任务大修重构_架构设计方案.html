数据流（单向依赖，避免成环）： B 产生外政状态(双线认可度/tension/从属/ActiveWars) → C 任务来源/属性/奖励读取 → C 任务完成回报 → B/好感回写。 好感一律走原版 Faction.TryAffectGoodwillWith/SetRelationDirect（与 BOTR 同路，零冲突）。 线程模型：决策核心可独立、一切执行写留主线程独占落 → 详见 外政核心_线程与事件决策模型.md。

加载边规则（AGENTS §2）： - B 只 patch WorldComponent_Territories.WorldComponentTick 与 BOTR def → 唯一 loadAfter 加 NehsModsForDev.bordersoftherim。 - B/C 引用帝国/美狐/Kurin 等派系 defName 属"全量加载后统一解析"，不加边（照任务大修已删 miho 边的教训）。 - 新增每条 loadAfter 前跑 _tmp/loadorder/find_cycle.py + check_order2.py 双口径验无环。

三、外政系统骨架（Layer B，新建）

设计要点（详见附录 §1–§2、§4）：

  1. 双线认可度：imperialStanding/freeStanding 两条 0–100 + 各自承认方集，按"是否落所选宗主从属树"分轨（字段/阶梯详见附录 §1）。
  2. 暗杀/谋杀（好感/敌对驱动）：目标线认可过低 或 BOTR FactionBorderContact.tension 超阈时解锁 ChoiceLetter；成败走原版 SetRelationDirect/健康 API，避开 BOTR 占的 CheckDefeated/Quest.Accept（附录 §2）。
  3. 帝国从属编排：三层组合 = 静态 permanentEnemyToEveryoneExcept + GoodwillSituationDef/Meow 破上限 + BOTR TerritorialDependency；宗主选 Empire（或 Rakinia/MedievalKingdom，附录 §4）。白名单 HMC 死条目禁抄。

进度（09-02）：P1 骨架/两暗杀队 def/P3a 金额系统给 已实装同步；详见 任务与悬赏体系优化.md §六。
