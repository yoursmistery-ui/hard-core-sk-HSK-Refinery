- **石器（Neolithic）不做任何限制**：不加蓝图、不门控任何节点，保持原样（需求#4）。

## 五、商人机制（需求#2 / #6 任务者售蓝图）

### 5.1 `StockGenerator_BlueprintTrader`（DLL 新增，用户修订版）

**规则（用户确认修订）**：中世纪/工业商人可卖「全套」蓝图但**稀有化**（每张低概率入库存、单次 1-2 个，无法一口气刷齐）；太空/极致商家**约半数卖、半数不卖**（同档内也非全量，随机子集）；纽拉(Neolithic)不卖。

| 商人派系 techLevel | 各 tier 库存权重基准 | 说明 |
|---|---|---|
| Neolithic | 全 0 | 不卖蓝图（需求#4） |
| Medieval | t1 高 / t2~t5 基线低 | 「卖全套但稀有」 |
| Industrial | t2 高 / t1、t3~t5 基线低 | 同上（t2 本期无门控则回落基线） |
| Spacer | t3 中 / t4~t5 高 | 约半数商家实例携带 t4/t5，另一半不卖（50/50 每实例投掷） |

**实现要点**：
- `StockGenerator_BlueprintTrader` 子类，`GoodsGenerator` 遍历 `BlueprintGateDatabase.AllBlueprintDefs()` → 读每张蓝图的 `BlueprintTargetExtension.tier` → 按「商人 techLevel + 上表权重」**加权随机**选库存；所选数量 1-2，**贵价**（按 2.1 售价系数，tier 越高越贵）。
- 权重表在 C# 中集中在常量区，便于**后续调整**（用户已说明可后续商量）。
- 用 xpath 存在性门控挂到通用商人 / 军火商 / RimQuest 任务者，实现「任务者出售蓝图」（需求#6）。
- 「不能一口气刷」由 RimWorld 商人库存随交易定期刷新（非每 tick 全量）+ 单次 1-2 自动满足。

## 六、卡节点动态概率（需求#3，性能优先）

### 6.1 卡节点检测（低频，不每 tick）

- 新增 `BlueprintStuckMonitor`（静态 + 事件驱动）：维护「当前卡住节点集」`stuckSet`。
- **绝不每 tick 全量遍历**：刷新时机 = ①科研完成（ResearchManager 触发）②任一蓝图被使用 ③地图加载 ④外加一个低频兜底（GameComponent `GameComponentTick` 每 600 ticks≈10s 仅自检一次"是否需要重建"，且当 stuckSet 非空才真正重建）。
- **卡住定义**：某门控节点 `PrereqsFinished==true`（可研究）但 `tracker.GetUseCount < unlockCount` 且未 `Unlocked` → 玩家需要更多该蓝图才能推进 = 卡住。
- 成本极低：遍历对象 = 约 40 张蓝图（非 map/pawn），即使 10s 重建一次也远低于性能红线。

### 6.2 动态提权（事件驱动）

- `PickRandomBlueprint()` 改为：**stuckSet 非空时 ~80% 从 stuckSet 优先选**；空则按原规则（70% 优先前置已满足）。
- 事件/任务生成处（Reward_ItemsStandard / AlliesGift / ItemStash / GoExplore 三途径 / 陨石 / 老人）读取同一判定：stuckSet 非空 → 各自本地概率上调（如 ItemStash 25%→45%、陨石 40%→60%、GoExplore 30%→55%、拦截/老人已 100%），未卡住时用基线。
- 这样「玩家卡住哪个→哪个蓝图就更容易被任何任务/事件产出」，形成正向反馈，且全部事件驱动、零每-tick 开销。

### 7.5 「任务为核心」落地要点（需求#6）

1. **任务奖励池**：`Reward_ItemsStandard` 已注入蓝图选项（weight 0.5），卡节点时按 6.2 偏向该节点 → 所有 RimQuest 任务=主要蓝图源。
2. **任务者售蓝图**：RimQuest 任务者（本身按派系 techLevel 分档）挂 `StockGenerator_BlueprintsByTechLevel`，任务者甲的兜里可买到对应时代蓝图（贵价）。
3. **任务刷新提权**：因所有任务共享 Reward_ItemsStandard，卡住时池内蓝图权重自适应 → 做任务更易得到卡住节点的图纸，形成「卡进度→做任务→解锁→推进」主循环。
4. 若需要更强的「针对性任务」：可选 C# 给 RimQuest 增加「蓝图护送/蓝图回收」专属 QuestScriptDef 分支（标为二期望选，本期可先不做以控风险）。
