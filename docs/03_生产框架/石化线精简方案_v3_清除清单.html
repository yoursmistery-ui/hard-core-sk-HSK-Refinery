六、残留风险（明确不清的）

  1. ChemfuelValve_Off / DeepchemValve_Off 未挂载 —— RimWorld 无"flickable 建筑自动换开/关贴图"机制，要自定义 Graphic 类才用得上。图已归档，需要时再立项。
  2. 卸货湾换皮是全局的 —— RefineryLoadingBay 是 Rimefeller 公共建筑，换皮后 Rimefeller 自己的 8 座精炼厂出料口也变漏斗。若不接受，删 Patch_RK_Petro_LoadingBay.xml 第一个 Operation 即可（过滤器扩展不受影响）。
  3. 合成氨/中性胺双来源 —— 本 mod 两台 clone 厂挂石化 III；Rimefeller 原版 SyntheticAmmoniaRefiner/NeutroamineRefiner 已被 Vile 改产丙烯/丁二烯，不再产氨和中性胺，所以实际不冲突。但若哪天 Vile 撤掉那层 patch，会出现两条来源。
  4. ProcessorFramework.dll 保留 —— 见施工图 §4-1，约束「勿删」。
  5. 三燃料精炼塔 / 润滑油 / 中性花瓣 —— 仍是草案，见施工图 §6。
  6. Unified.xml 基线过期 —— 现那份是 08-29 10:26 导出的，不含 v3 新 def；本轮审计里"本 mod 自身 def"走的是实扫，不受影响，但下轮若再以 Unified 为唯一基准会漏判。
