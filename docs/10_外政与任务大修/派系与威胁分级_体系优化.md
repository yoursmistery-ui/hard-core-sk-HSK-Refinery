# 派系与威胁分级 · 体系优化

> 立档 2026-09-02。性质：**优化方案**（接 [`外政与任务大修重构_架构设计方案.md`](./外政与任务大修重构_架构设计方案.md) / [`任务与悬赏体系优化.md`](./任务与悬赏体系优化.md) / [`天网Skynet_boss整合.md`](./天网Skynet_boss整合.md)）。
> 纠偏：外政/悬赏不针对"少数几个派系"，而覆盖**全谱 77–79 个派系**；天网(Skynet)定为体系**最终 BOSS**。

---

## 一、派系全谱：按"系统角色"自动归类（不逐派系手填）

所有子系统只 key on **派系属性 + 科技档**，新加入的 mod 派系自动纳入，不维护名单。

| 角色 | 判据（属性） | 参与的子系统 | 规模 |
|---|---|---|---|
| 帝国线宗主/从属 | `defName==Empire`，或 `BotrBridge.IsSubjectOfEmpire`（读 BOTR `TerritorialDependency`） | 双线认可度·帝国线、外交、战争委任、从属间禁开单 | 1 + 动态从属树 |
| 民间可贸易/可委托 | `BountyRules.IsWorldNpcFaction`（可见+humanlike+未灭+非玩家） | 悬赏/通缉/暗杀委托/结盟/双线认可度·民间线 | ~52（可见人类系） |
| 敌对 raid 极 | `permanentEnemy` 或 `HostileTo(player)` | 袭击档案、猎杀/通缉单、敌对线好感代价 | ~20 |
| 隐藏服务派系·刺客公会 | `defName∈{Kurin_Faction_Hostile, Miho_Faction_Supremacist}` | **暗杀委托直供方**（`AssassinGoodwill` 结算对象）、隐藏贸易据点 | 2 |
| 隐藏幸存者 | `HumanResistance`（hidden, naturalEnemy=false） | 特定事件/委托接入、可中立 | 1 |
| **最终 BOSS·机器天网** | `SkynetHumanlike`（hidden + permanentEnemy + !humanlike） | **仅走「天网 boss 定向战令」**（不入外交/悬赏/暗杀，因 hidden+machine 被 `IsWorldNpcFaction` 排除） | 1 |

> 现状核对：外政页签/双线认可度/暗杀源已按上述**属性判据**取派系（`WorldComponent_EdgePolitics` 按任意 `faction.loadID` 存、`EdgeBridge.OnImperialLine` 走 BOTR），不是写死几个——UI 演示里只见 6 个是取样，非上限。

## 二、威胁 / BOSS 分级阶梯（对齐任务 T1–T4 + 终章）

| 级 | 内容 | 来源 | 解锁 | 奖励档 | 失败代价 |
|---|---|---|---|---|---|
| **T1 地方** | 寻物/驯捕/低阶通缉 | 无线电/面对面/随机 | 常开 | 低 | 无 |
| **T2 领地** | 清剿据点/族色委托 | 族色发单/玩家发布 | 常开 | 中 | 无 |
| **T3 外政** | 定向暗杀委托（公会/NPC patron）、勒索 | `TryAssassinContract`/公会直供 | 目标线认可过低 或 `tension` 超阈 | 中高 | **不扣好感**（本设计核心） |
| **T4 战争** | 派系战争委任、区域大 boss | 读 BOTR `ActiveWars`/`TerritorialMission` | 处于/邻接战事 | 高 | 战线挫败 |
| **T5 终章** | **天网(Skynet)最终 boss**：`SkynetPrototypeTX`(MV≈130000)+T-800+T-Cyborg | **天网 boss 战令专章**（Layer C 定向，非公告牌） | 后期/外政进度触发（见 §四） | 极高 + 全派系声望 | 反扑升级 |

天网**不进普通悬赏**（hidden 机器族）；击杀它 → **双线认可度大涨 + 帝国线/民间线同时声望**（把最终 boss 与外政进度绑定，见 §四）。

## 三、可扩展原则（保证"不止这么点"）

- 认可度/悬赏/暗杀/战争全部 key on 角色属性 + 科技档，**无枚举名单** → 加新 mod 派系即自动进池。
- 双线认可度：`imperial/freeStanding` 按 loadID 存，任意 WorldNPC 派系天然可持有；帝国线归属由 BOTR 从属树动态判定（宗主可换 `OverlordDefName`）。
- 参数集中在 `RewardCurveDef`（tier/prepay/认可度上浮与增量）+ `WorldComponent_EdgePolitics`（阈值 60、宗主名），**改值不重编**。

## 四、优化点清单（相对已实现）

1. 天网 boss 战令与终章链：`天网Skynet_boss整合.md` 已定 T4 定向战令；**优化**=把 T5 触发挂到外政进度（玩家帝国线认可度达阈 或 BOTR 某条件 → 放"天网觉醒/ Salvation 事件"，多阶段 侦察→入侵→终章）。
2. 击杀天网结算：`SkynetPrototypeTX` 死亡 → 触发全派系双线认可度大涨（经 `EdgeBridge`）+ 终章信。
3. 外政页签已列全 WorldNPC 派系（无截断）；可加**按线/认可度排序 + 派系旗帜图标**。
4. 刺客公会直供已优先（`IsAssassinGuild` patron）；后续可加"公会据点被袭 → 玩家驰援"支线。
