# Reel存储HSK适配（整合版）

把 **Reel's Expanded Storage** 的 16 个存储建筑（定义+贴图）**完整整合**进本地 mod，
**无需安装** Reel's Expanded Storage 与 VFE Props and Decor，仅依赖 **Adaptive Storage Framework**（已启用）。

- packageId: `local.reelstorage.hskfix`
- 部署目录: `RimWorld\Mods\Reel存储HSK适配`（工作区源码: `Reel存储HSK适配/`）

## 依赖

| mod | packageId | 状态 |
|---|---|---|
| Adaptive Storage Framework | adaptive.storage.framework | 已启用 ✅ |
| HSK (Hardcore SK) | skyarkhangel.hsk | 已启用 ✅ |

**无其他前置**。Reel 本体与 VFE Props 已从 Workshop 移除，不影响本 mod。

## 包含内容

- `1.6/Defs/ReelStorage_ThingDefs.xml` — 16 个存储建筑定义（研究接入 HSK Storage 线、数值加强、中文化）
- `1.6/Defs/ReelStorage_GraphicsDefs.xml` — 32 个 ASF 渲染配置（AdaptiveStorage.GraphicsDef）
- `1.6/Textures/` — 129 张贴图（Reel 自创 101 张 + VFE Props 6 个建筑 28 张，含方向变体）

## 建筑师二级菜单（ArchitectSense 子分类）

19 个建筑在建筑师「存储」分类（ASFstorage）下，通过 **ArchitectSense.DesignationSubCategoryDef** 分 5 个子分类显示（与鼠族家具同一机制，游戏内分组标题+建筑网格）：

| 子分类 | 建筑 |
|---|---|
| **木质仓储** | 储物桶、大型木箱、板条木箱、储物书架、工业货架 |
| **工业货箱** | 金属货箱、大型金属货箱、货运集装箱、桶装托盘、立式武器架 |
| **冷藏存储** | 冷藏冰箱、医疗冷藏柜、厨房小冰箱、卧式冰柜、冷藏卡车 |
| **工业废料** | 工业废料箱 |
| **太空存储** | 太空集装箱组、太空储物柜、大型太空集装箱、小型太空集装箱 |

中世纪/太空建筑为可材质化（选材质→建造），工业建筑固定材料直接建造。
