2. MO 原版语义(反编译依据)

反编译源: workshop\content\294100\3219596926\1.6\Assemblies\MedievalOverhaul.dll(ilspycmd)

  • RequiredSchematic : DefModExtension { ThingDef schematicDef } 挂在 ResearchProjectDef 上。
  • CanStartNow postfix → PlayerHasSchematic: 遍历 Find.Maps 殖民地建筑的 Building_ResearchBench,查其所在房间 uniqueContainedThings 中 Building_Bookcase.HeldBooks 是否含目标图纸 → 无则不可开始。
  • CanBeResearchedAt postfix: 同逻辑但逐研究台判定(该台自己房间里有没有)。
  • 阅读侧: BookOutcomeProperties_GainResearchDefinable 继承原版 GainResearch,doer 的 OnBookGenerated 里 values[项目]=GetBaseValue()×gainMultiplier,原版 OnReadingTick 在读书过程中分摊科研值。
MO 缺陷(复刻时已修): 两补丁共用静态单槽缓存,跨研究台/跨图纸会串结果 → 我们改为按 schematicDef / 按 bench 的双字典缓存。

  • CanStartNow getter postfix: 全局判定,缓存 Dict<schematicDef,(bool,到期tick)>,250 tick。
  • CanBeResearchedAt(bench,bool) postfix: 逐台判定,缓存 Dict<bench,(def,bool,到期tick)> —— 修 MO 单槽串台 bug,def 变更自动失效重算。

    <defName>Schematic_XXX</defName>

    <description>…放入研究台同房间书架即可解锁…</description>

        <li Class="SchematicGateHSK.SchematicBookExt">

    </modExtensions>
