## 4. 施工中改判的三处（与原计划不同，已核实证据）

1. **`ProcessorFramework.dll` 不移除 —— 约束：勿删**。原 v3 草案 §10「风险」段判它"混入 Assemblies 违反铁律，本轮一并移除"，**该表述作废，以本节为准**。实测：该 DLL 与 `BlueprintUnlockHSK.dll` 同尺寸但 **hash 不同、程序集名不同**（内含 `ProcessDef`/`ProcessorFramework` 命名空间），是 About §十 明确声明"内置融合、请勿再装 PF 本体"的框架 DLL，且 `Buildings_Rustic_Processors.xml` / `ProcessDefs_Rustic.xml` 全部 def 依赖它。铁律禁的是**同名单残留测试 DLL**（`.new`/`.bak`/`.p5` 之类），此处不适用 → **保留，任何后续清理不得顺手删**。
2. **精炼厂出料口不能自建**。反编译 `CompRefinery` 确认它按 `DubDef.RefineryLoadingBay` **defName 硬找**相邻卸货湾，自建同功能建筑不会被认领 → 出料口改为"沿用 Rimefeller 建筑 + 换皮 + 扩过滤器"。
3. **产物落地不经过滤器**。`CompRefinery` 用 `GenPlace.TryPlaceThing(..., Direct)` 强吐，扩过滤器不是为"能吐出来"，而是让卸货湾**认领**这些产物（否则小人当外来物搬走）。

## 5. 两处按现有机制收敛的偏差

- **铺路"移速加成"**：`TerrainDef` 无 `moveSpeed` 字段，移动只走 `pathCost`；全量 Unified.xml 无任何负 pathCost 先例，负值会破坏 A\* 非负代价前提 → 改为 `pathCost 0`（与原版柏油路同档，不拖慢）+ 文案表达，另给 `CleaningTimeFactor 0.6`。
- **管网研究挂位**：原计划只写"DeepCracking→AtmosphericDistillation"。实际按介质拆开：天然气管网（管/阀/泵/出料口）挂 **I·常减压蒸馏**（与蒸馏塔、燃气发电机同期可用），氨气管网挂 **III·连续合成**（与氨储罐、合成氨精炼厂同期）。
