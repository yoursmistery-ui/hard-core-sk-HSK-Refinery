## 一、机制要点与取舍(与原设计/原 MO 的差异, 均有理由)
1. **“圣物递进”= 点数递进**: 无 VEF Storyteller 节点可把站点派系钉死在 MedievalKingdom(实测本环境 VanillaExpandedFrameworkLocal 只有 KCSG.dll, 不含 VEF.Storyteller.*), 故任务脚本按族色原版机制 `GetSitePartDefsByTagsAndFaction + mustBeHostileToFactionOf $asker` 自动选“现有敌对派系”。四档按 rootMinPoints 400/1000/1700/2400 逐级在 RimQuest 池中出现, 蛇窟(2400)为终点 —— 满足“情报道具递进解锁 + 挂现有敌对派系”, 但不做存档级“拿到上一档圣物才解锁下一档”的硬门槛(那需要 DLL, 用户方案已定零新 DLL)。
2. **派系随机化提示**: 站点敌人=委托人当前的敌对派系部队 + 布局里的邪教/蛇符号(同派系, 敌我判定统一); 若该派系科技高, 邪教符号仍强制穿 HSK 甲+兜帽(required), 武器只按 medieval tag 给。
3. **蛇只做战斗/场景敌人**: 不养殖(砍蛋/驯养), 蛇窟里 = 毒蛇群 + 巨蟒做 Boss; 眼镜蛇 corpse 无肉无皮问题由引擎自动 Meat_/Leather_ 兜底。
4. **任务不进悬赏板**, 符合用户拍板“圣物递进+自动刷出”; RimQuest 池权重低(3/2/1/1), 不会刷屏。
