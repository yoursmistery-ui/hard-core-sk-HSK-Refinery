## 一、终态全链路

```
地下原油 → 油井(Rimefeller) → 石油CrudeOil
  → 常减压蒸馏塔(原版石油精炼厂皮·bill 8档)
      → 化合燃料 / 天然气 / 沥青(石脑油皮)            ← 石脑油删除，沥青回归
  → 三燃料精炼塔(美狐高炉皮·管道连续厂)
      进料: 天然气 + 沥青 + 化合燃料 三管道，均 >50% 才运作
      产物: 三烯(乙烯/丙烯/丁二烯) + 二苯(苯/二甲苯) + 超织物
      废物: 炼油油泥(污染物·内部槽)
  → 合成氨精炼厂(连续厂·绿管机新贴图)   天然气 → 氨（管道进·管道出·接水）
  → 中性胺精炼厂(连续厂)   天然气 + 化合燃料 → 中性胺
  污染物: 炼油油泥(蒸馏塔+三燃料精炼塔统一副产·内部槽) ← 唯一污染物(焦油渣已删)
      → 污染物发电机焚烧发电 / 原子化器销毁 / 冻结封存
  终端: 三苯三烯 → VMS 下游(Nylon/Zylon/橡胶)；中性胺 → 药品/弹药；氨 → 化工/药品
```
