## 二、对方案的三处改判（都朝"更安全"方向）

1. **新建 def 从 9 个增到 26 个**。原计划把 13 个现成 def 直接当轴节点用，实施前发现两类风险：① 现成 def 已有成员挂着，再按新轴语义追加会与既有条目撞 `duplicate thingCategory`；② 部分 def 语义与轴节点不完全等值（如 `AccessoriesCat` 成员全是面部件，当"面饰眼部"轴节点没问题，但它自己还有 9 件历史成员）。改为**轴节点一律新建，现成 def 降级为其子分类**——零重复风险，且旧分类的汉化、`Vile_Mending` 收料、深空船库存全部原样可用。
2. **本地 434 件不直接改 Defs 文件，改为各本地 mod 自带 Patches**。用 lxml 就地改 def 会重排整个文件、造成大面积无意义 diff；补丁形式归属不变（仍在自家 mod 内）、且 P2 阶段可整文件回滚。
3. **一级节点 5 个而非 4 个**：多出一个 `HSK_ApparelLegacy`「旧种族分类（归档）」抽屉，用来安置 `RK_Apparel`/`Miho_Apparel`/`Kurin_*`/`OARatkin_*` 等 19 个种族桶。不删 def、不改 defName，只换 parent，避免任何悬空引用。

## 六、游戏内反馈修复 ①：分解衣物等原料选择窗口只剩科技档（已修）

- 现象：存储区筛选正常（五枝俱全），但**工作台账单的原料选择**（分解/熔化/烧毁衣物）里只剩 ①原始…Archotech 终极 6 个科技档，搜索也搜不到其它分支。
- 根因（反编译确认）：`Verse.ThingFilter.RecalculateDisplayRootCategory` 在"子树包含全部 allowedDefs"的节点里取**遍历序最后一个**当显示根；带 `parentFilter` 的窗口（账单原料选择等）用 `parentFilter.DisplayRootCategory` 当树根。三根轴各自都装着全部 910 件 → 声明序最后的 `HSK_ApparelTech` 劫持了所有此类窗口。存储区窗口 `parentFilter=null` 走总根，不受影响。
- 结论：**引擎算法与"三轴正交全覆盖"天然冲突，XML 无解**——改声明顺序只是换一根轴劫持。
- 修复：`HSK修复整合/Source/ApparelAxisRootFix.cs`（Harmony postfix `RecalculateDisplayRootCategory`）：算出的显示根若为 `HSK_ApparelPos/Use/Tech` 之一，回退到公共祖先 `Apparel`。窗口恢复显示五枝（原结果超集，只损失自动收窄的便利）；窄过滤（只允许某几类服饰）算出的根不在三轴上，原样放行。纯显示层，不改 allowedDefs 与存档。HSKFixPack.dll 已重编部署（workspace=deployed sha256 一致）。
- 复算脚本：`_tmp/apparel_cat/` 下以 `final_cats.json` + `plan.json` 模拟"包含全部 def 的节点 DFS 序最后者"，修复前输出 `HSK_ApparelTech`，修复后由 DLL 回退为 `Apparel`。

## 七、游戏内反馈修复 ②：Androids 两件显示为根节点游离叶子（已修）

- 现象：筛选树里 `保温裹身布`(ChJAndroidThermalBandages) / `燃料发电机`(ChjAndroid_ChemfuelGenerator) 直接挂在根上，看着"没有分类分级"。
- 根因：这两件的**原始 def 自带裸 `<thingCategories><li>Apparel</li></thingCategories>`**（全 910 件里只有这 2 件如此，lxml 扫 Unified.xml 确认）。显示根正是 `Apparel`（见第六节回退），裸挂父分类的 def 会在根节点上当直叶子列出，其余 908 件只挂子分类故全部折叠进枝里。
- 修复：59_服饰三轴挂载.xml 把这两件的 Conditional-Add 改成 `PatchOperationReplace` 整块重写 thingCategories（只留三轴，带 `Inherit="False"`）。lxml 模拟：各命中 1 节点，终态 `[HSK_P_Under|HSK_P_Acc, HSK_U_Daily, RK_Apparel_*]`，无裸 Apparel。
- 通用规则：**给 def 补三轴时，若原 def 直挂的旧分类就是显示根（Apparel/Item 等），必须 Replace 掉而非追加**，否则该 def 在树上散落在根层。
