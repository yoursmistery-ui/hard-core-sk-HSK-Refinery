> 权威流程图 = 用户 mermaid 定稿（见 `石化工业线_自建架构总纲.md` 顶部 + `…_最终流程图与可行性.md`）。本文是**落地框架总览**：链路、复用边界、美狐建筑新角色、气网/危害、断水、决策记录、现状与验证清单。全部并入 `HSK工业科研大修`（`ratkinpatch.HSKIndustrialResearchOverhaul`），不新建独立 mod。

### 0. 复用/自建铁则（08-28 定, 二轮补第 4 条）
- **精炼层保持 Rimefeller 原版**：5 座 `*Refiner`（乙烯/丙烯/丁二烯/苯/二甲苯精炼厂）是**管道连续生产者**（`CompProperties_Refinery:CompProperties_Pipe`，chemfuel 进料、无账单槽），即流程图里的"精炼厂"本体，**不做 bill 式精炼台、不新增"精炼X"中间物**。三烯三苯 = 精炼厂连续产 + 精馏塔批量产，双源直供工作台。
- **胺链维持既有铁律**：胺类=中性胺(Neutroamine)，去精炼、只从中性胺合成塔产，直连工作台与药品/弹药。流程图右下"胺类化合物→精炼胺类"段**不实现**。
- **氢气并入天然气（08-28 二轮定, 已落地）**：氢物品/氢储罐/氢气管·泵·阀 3 座建筑全删；合成氨改为天然气×20、中性胺改耗氨+天然气+乙烯、催化重整副产改天然气；锅炉/发电机 fuelFilter 只留天然气；两合成塔 Deposit 囤气 Sink 改天然气（氨塔 24、胺塔 12）。DLL 侧 `PetroGasUtil.Norm()` 把 `PetroGas.Hydrogen` 归一化为 NaturalGas（枚举值保留），**老存档的氢气瓶读档即天然气瓶、残留氢管网自动归天然气管网**。
- **美狐两建筑改色上岗**（原为 1.6 死 def，贴图在 `Cont/` 会加载）：美狐高炉→**常减压蒸馏塔**换皮（原方案 §1 即规划"蒸馏塔用美狐高炉壳"）；美狐天界熔炉→新建**原油裂解炼油厂**（路线A bill 工作台）。

### 1. 全链路（上游→终端）
```
地下原油 → 油井(Rimefeller) → 石油CrudeOil
  → 常减压蒸馏塔(自建·美狐高炉皮) → 主:化合燃料Chemfuel / 副:天然气·石脑油·沥青
      → 各储罐(自建·Rimefeller压力罐改色) → 气(天然气/氨) 走"通用气管网"
  能源: 燃气发电机 / 燃气锅炉 ← 天然气(气管网/气瓶)
  路线A 原油裂解炼油厂(自建·美狐天界熔炉皮)  Chemfuel → 合成烯 / 合成酰胺 / 超织物(Hyperweave)
  路线B 深度裂解厂  气+沥青+燃油+石脑油 → 裂解混合气 → 精馏塔 → 三烯(乙烯/丙烯/丁二烯)+三苯(苯/甲苯/二甲苯)
  路线C 催化重整装置  石脑油 → 苯/甲苯/二甲苯 + 副产 天然气
  路线D 氨合成塔  天然气×20 → 氨(SyntheticAmmonia);  中性胺合成塔  氨+天然气+乙烯 → 中性胺
  石化工作台  三烯三苯 + 合成烯/酰胺 + 中性胺 → 合成树脂/合成纤维/合成橡胶 + 医药产品(Medicine)
```

### 3. 通用气管网（双介质分线, 08-28 二轮氢并气后）
- 介质 `PetroGas`{天然气/氨}，各一套管/泵/阀 def（6 座），`linkFlags` Custom1/2 分线；`MapComponent_GasNet` 邻接并查集**仅同介质 union**，绝不互串。
- 气源=储罐(`role=Source`)，用气端=锅炉/发电机(`role=Sink` FuelPool)、氨合成塔耗天然气(Deposit 囤 24)/中性胺塔耗氨+天然气(Deposit 各囤 12，投松气到装置旁供 bill)。气泵通电提通量，气阀关即断网。
- 便携气瓶单 def 双介质通用（`CompGasCylinder.kind`），储罐"灌装气瓶"，满瓶放装置旁自动虹吸。
- 危害：氨节点 `CompGasToxic` 泄漏 → 原生 `map.gasGrid.AddGas(ToxGas)` 毒气云；玩家主动拆除不触发。氢缩放爆炸(`CompGasExplosive`)随氢删除不再被任何 def 引用(类保留兼容)；天然气罐沿用固定半径 `CompProperties_Explosive`。

### 4. 断水停机
9+1 座耗水装置挂 `CompNeedsWater`（反射 Dubs 卫生 `CompWaterStorage` 低频抽水，未装卫生→永不缺水）；工作台缺水经 Harmony 前缀 `WorkGiver_DoBill.JobOnThing` 停发加工单，锅炉/发电机缺水 `CompFlickable` 自动关断、水回补自恢复。补水靠卫生供水管网自动灌。

### 5. 研究节点（自有五档链，Craft_SK Y=28）
`RK_Petro_AtmosphericDistillation`(I·蒸馏) → `DeepCracking`(II·裂解与燃气利用，含气管网/气瓶/原油裂解炼油厂) → `FractionationReform`(III·精馏与重整) → `Ammoniation`(IV·合成氨与中性胺) → `Polymerization`(V·高分子合成，含医药)。入口仅 `Oil_Industry_C2`+`Electricity`，逐级自锁，全 Industrial 挂 IndustrialBase，无越级。
