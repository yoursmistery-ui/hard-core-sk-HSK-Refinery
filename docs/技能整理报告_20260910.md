## 二、消重结果:通用铁律收敛到一处

- `PatchOperation` 只作用 xpath 首个命中 / xpath 无 union

- About.xml 需转义 · 语言文件夹命名 · ModsConfig 备份
- 坐标源只认运行时终态 `Mods/Unified.xml`(UTF-16,必须 Python 读)

**顺带提升**:两条此前只存在于项目 memory、未进任何技能的硬铁律,现已写进伞技能 §4 ——

- **ASF**:`ParentName="AdaptiveStorageBase"` 必须配 `<AdaptiveStorage.GraphicsDef>(targetDef=本def)`,缺则每帧 NRE、建筑完全不画
- **菜单图标**:设了 `uiIconPath` 就跳过 `IconDrawScale` 补偿 → 画布须裁透明留白且比例 = `drawSize`
