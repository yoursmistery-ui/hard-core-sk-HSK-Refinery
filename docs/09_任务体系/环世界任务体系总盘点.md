# 环世界(HSK)任务体系总盘点

> 范围:当前存档 `ModsConfig.xml` 全部启用 mod + 已装 DLC。日期 2026-08-28。
> 详版(逐 def 表格)见同目录 `环世界任务体系总盘点.html`。
> 数据源:ModsConfig · Unified.xml(终态)· QuestScriptDef + IncidentDef 源文件 · OberoniaAurea/BOTR 框架 DLL · ilspycmd 反编译。
> 本文用**双视图**组织:§1 按"任务从哪来(机制)"建树,§2 按"哪个派系给的(派系树)"交叉重排。

## 0. 结论

全游戏**没有独立"任务板/悬赏委托"mod**。任务统一走原版 `QuestScriptDef` 框架,由四类投递通道 + 结局线送达;原版 + 4 DLC(Core/Royalty/Ideology/Biotech/Odyssey,**Anomaly 未启用**)是骨架,**10+ mod/框架**填自定义任务。
⚠ 三易错:`Vortex Kingfisher` 是纯性能补丁(非钓鱼任务,排除);**event mod ≠ 任务 mod**(Cybranian 18 事件仅 2 个是任务);只 grep `QuestScriptDef` 会漏 GoExplore/Minerals(纯 IncidentDef 世界据点)与 OA框架/金鼠族/边境(DLL 生成)。

## 2. 派系任务树 —— 按"谁给的"

**[金鸢尾兰 OberoniaAurea]** 金鼠族HSK版本(+Odyssey子mod,地基=OA框架 DLL):门控要求 OA **非敌对**;通用货币 = 支援点数/逆重协助点/王权好感/好感;三主线(好感·支援点线、风雪遗孤剧本线、奥德赛逆重线),~28 任务。**"暗杀"=`OA_OpportunitySite_PunishmentExecutor`**(据点处决目标,奖 威胁点×1.75+王权好感+支援点+20+空投轨道光束指示器,4~8天,招1~2波报复);全 mod 无另一"assassin"def。

**[鼠族系]** 鼠族HSK拓展 + RatkinRaceHSK:
- Rakinia_Waster 垃圾鼠帮 → 垃圾鼠据点(袭/援,交10咪咪片转永久营,全图≤2)+ 流浪者来投(base0.3)。
- 鼠族信仰 → ReliquaryPilgrims_Ratkin 朝圣(可重复)+ PriestJoin 祭司(60天后单次)。
- 鼠族叙事者 Rotty Milden → 整体放大委托·访客·商队密度。

**[交战中各派系]** 边境拓展HSK(BOTR):不绑单派系,由领土战争模拟实时生成 6 类契约(夺指挥/守边/解围/断补给/护送/守城),DLL 邀约频率控制,不走叙事者池;银币(×报酬强度,承认政府+20%)+好感+政治地位。

**[美狐 Miho/帝国]** 美狐HSK拓展:`Intro_MihoScav` 一次性 intro,奖1名特殊殖民者,代价=帝国-100转敌对+突袭。

**[无派系/设施给]** Cybranian(OldMan+WorldMeteorite)、GoExplore(5据点)、Minerals(富矿)、LAO(小行星):走事件 baseChance 或设施主动触发。

**[原版+DLC]** 帝国/殖民者盟友的接待·法令·授勋·封臣·贸易请求·坠落来投·圣物朝圣·机械委托:A/B/C,好感+进度分门控。

## 3. 刷新 / 门槛规则

随机委托能否出现由 `NaturalRandomQuestChooser.GetNaturalRandomSelectionWeight` 定:
- **进池前提** `rootSelectionWeight>0`(0=走专属通道)。
- **三重门槛** `points≥rootMinPoints` · `开档天≥rootEarliestDay` · `进度分≥rootMinProgressScore`。
- 同任务 `minRefireDays` 冷却;最近5任务 `RecentRandomQuests` 逐级降权(不连刷)。
- **一次性/唯一** `QuestPart_Unique restriction=UniqueSuccess/UniqueAvailable`;并发 `maxSpawnCount`。
- **事件通道另一套门槛**(B/D):`baseChance`·`minRefireDays`·`earliestDay`·`minPopulation`+人口曲线。
- 好感/敌对门控:金鼠族普遍要 OberoniaAurea 非敌对。

## 5. 坑与口诀

- `Unified XML Export` **只导 `QuestScriptDef`,不导 `QuestDef`**(176/0),原版奖励表在 `Data/` 打包。
- **盘点不能只 grep `QuestScriptDef`**:须并查 `IncidentDef`(GiveQuest/Misc)+ 框架 DLL。
- **event mod ≠ 任务 mod**:真任务看 worker `IncidentWorker_GiveQuest` / category `GiveQuest`。
- `Vortex Kingfisher` 无 XML/Defs,纯性能补丁,勿列为任务mod。
- **Anomaly 未启用** → 无异常/恐怖任务线。
- 选 **Rotty Milden** 叙事者会放大委托·访客·商队密度。
- 金鼠族/边境/Ratkin/OA框架**真逻辑在 DLL**,XML 只文案+门控或空壳;改数值多半不在 XML,要精确到每条委托须反编译框架 DLL。
