三、本轮定稿的四个开放问题

  1. 管网重做范围 = 只换贴图。def 结构（1×1、linkType=Basic、linkFlags Custom1/Custom3、Conduits 层、危害 comp）全部沿用，仅 texPath 换成新底图并补 blueprintGraphicData。旧自绘图集是 534×534（4×4 切分不整除，亚像素错位），新底图 640×640 标准四切。
  2. 出料口定位 = 两条腿。① 自建 RK_Petro_GasTap_{NG,Ammonia}（1×1，CompGasPort role=Sink mode=Deposit）把气以罐装形态落地，供无管道工位；② 精炼厂出料口不能自建 —— CompRefinery 按 DubDef.RefineryLoadingBay defName 硬找，所以沿用 Rimefeller 建筑，只做换皮 + 扩存储过滤器。
  3. 储罐换皮 = 不换。三座立式罐保留自绘图（与装置贴图同一套画风），只把已删的卧式四向罐图清出 mod。
  4. 三燃料精炼塔草案 = 不纳入本轮，阀门素材已备（见 §四）。
