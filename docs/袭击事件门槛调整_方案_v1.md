## 1. 现状读取（限制链路全览）

这套环境里"大威胁何时出现"由 3 层叠加控制，改动必须落在**正确的层**上：

| # | 层 / 文件 | 机制 | 涉及对象 |
|---|---|---|---|
| L1 | `HSK修复整合/Patches/13_袭击首日延期.xml` | FactionDef `earliestRaidDays`（年限） | Mechanoid / Insect / Insectoid |
| L2 | `HSK修复整合/Source/RaidHelperWealthTech.cs`（HSKFixPack.dll） | Harmony：SK `RaidHelperComponent.ResolveFaction` + 原版 `IncidentWorker_RaidEnemy.TryResolveRaidFaction` 双路设门槛 | 普通派系=科技档上限(玩家+1)；机械/虫族=豁免科技、改吃财富（Mechanoid 50万 / Insect+Insectoid 100万）；增援 400 天 |
| L3 | `Core_SK_CoreModule/Patches/Core/Storyteller/Incidents_Map_Threats.xml` | IncidentDef `earliestDay 170` + `minThreatPoints 8000` + SK worker | 心灵飞船 PsychicEmanatorShipPartCrash / 枯萎者 DefoliatorShipPartCrash |
| L4 | `Core_SK/Defs/Storyteller/*.xml` | IncidentDef `earliestDay`/`minThreatPoints` | HSK 大事件（GeoStorm/PortalRaid/Bombardment/PowerBeam/Terraformer 等，earliestDay≥200） |
| L5 | `Skynet_SK/Defs/FactionDefs/Skynet.xml` + `Defs/IncidentDefs/Incidents_Skynet.xml` | FactionDef `earliestRaidDays 260`、曲线 11000 点起；事件 `earliestDay 180`、`minThreatPoints 7000~7500` | 天网 SkynetHumanlike / Salvation / AgentPodCrash / AgentTravelerGroup |
| L6 | `Faster raids progression`（已启用，index 92，早于 hskfixpack 221） | Patch 覆盖：天网 `earliestRaidDays→180`、曲线→10000 点起、事件 `earliestDay→160`；Asari/Norbal 等多族 | **会被 L1/L2/L5 反向覆盖（后加载者胜）** |

**关键结论**：
- hskfixpack（221）在所有相关 mod 之后 → 在其上加补丁即可稳定覆盖 L3/L5/L6。
- 年限=纯 XML 可改；**科技档下限**对 raid 走 DLL（沿用现有 FactionAllowed 框架），对"事件型"（心灵飞船/天网 3 事件）须**新增 IncidentWorker 触发钩子**（原生 IncidentDef 无科技字段）。

## 3. 实现分层

### 3.1 纯 XML（年限）
1. **改 `13_袭击首日延期.xml`**：Mechanoid 320→180、Insect 480→240、Insectoid 480→240（文件注释同步更新，语义从"延期"变"3~4年档"）。
2. **新增补丁**（并入 hskfixpack Patches，建议新文件，覆盖 L5/L6/L3 后置位）：
   - `SkynetHumanlike`：`earliestRaidDays 180→120`；`raidCommonalityFromPointsCurve` 起点威胁点抬到 12000+（财富曲线拦低财富天网）
   - `Salvation / AgentPodCrash / AgentTravelerGroup`：`earliestDay 160→120`
   - `PsychicEmanatorShipPartCrash / DefoliatorShipPartCrash`：`earliestDay 170→120`（覆盖 L3）

### 3.2 DLL（科技档下限 + 财富门槛）
扩展 `RaidHelperWealthTech.cs`（**必须**，因科技门槛无原生字段）：

1. **Raid 派系准入**（改现有 `FactionAllowed`）：
   - 把"机械/虫族豁免科技、只看财富"改为**按表判定**：`玩家科技档 ≥ MinTech(f) && 财富 ≥ WealthGate(f)`。
   - 表：Mechanoid=Industrial/100万；Insect+Insectoid=Medieval/50万；SkynetHumanlike=Spacer/200万。
   - 其余普通派系维持现有"上限=玩家档+1"不动。
2. **事件型门槛**（新增对 `IncidentWorker.CanFireNow` 的 Prefix，按 `def.defName` 判表）：
   - 心灵飞船/枯萎者 → 玩家 Industrial+ 且财富≥约80万（威胁点口径可换算，见 §4 待确认）
   - 天网 3 事件 → 玩家 Spacer+ 且财富≥200万
   - 命中门槛即 `__result=false; return false`。
3. 重新编译 HSKFixPack.dll（须先退游戏释放 DLL 锁），工作区+部署双目录同步。
