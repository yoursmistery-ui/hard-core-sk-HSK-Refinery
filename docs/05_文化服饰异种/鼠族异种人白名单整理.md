# 鼠族异种人白名单整理

> 2026-08-26 整理,2026-08-27 增补(9 号语义反转 / §6.7 智人种定论 / §7 美狐派系池)。白名单内容分散在 1 个基础 mod + 5 个补丁文件里,本文按「最终生效态 → 来源明细 → 派系池」三层梳理,并把最终态拼成可直接复制的 XML。
> 术语: **xenotypeList** = 该种族允许生成的异种人白名单(HAR raceRestriction);**whiteGeneListEndo** = 内源基因(endogene)可继承白名单,配合 `onlyHaveRaceRestrictedGenesEndo=true` 使用。两者只作用于 `defName="Ratkin"`(及 92 号顺带处理的人类/阿莎丽),不影响其它种族。
