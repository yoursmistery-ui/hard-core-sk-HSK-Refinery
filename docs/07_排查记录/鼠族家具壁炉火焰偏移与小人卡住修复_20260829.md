# 鼠族家具壁炉两 bug 修复记录（2026-08-29）

对象：`鼠族家具拓展`（packageId `local.ratkin.furniture`）`Defs/RKFC_JoyTemp.xml`
涉及 def：`RKFC_RGK_Fireplace`（柴火版）、`RKFC_RGK_FireplaceE`（电动版）

## Bug 1：火焰位置偏到建筑下方

**根因**（反编译 `Verse.Graphic_Flicker.DrawWorker` + `CompFireOverlay`/`CompProperties_FireOverlay` 定论）：
火焰绘制位置 = `parent.DrawPos`（=TrueCenter，footprint 中心，不含 drawOffset）+ **建筑自身 `graphicData.DrawOffsetForRot(rot)`** + **FireOverlay 的 `Props.DrawOffsetForRot(rot)`**。
壁炉 south 朝向 `drawOffsetSouth=(0,-1,0)`（高度下移 1 格），火焰经 DrawWorker 继承同一 -1，故火焰中心本就落在炉膛口——**位置其实没错**。真正问题是昨天补 `CompProperties_FireOverlay` 时 `fireSize=1.4` 过大：火焰 quad 以中心铺满 fireSize 倍，1.4 时下半截从炉膛垂到基座/地面以下，视觉即"火画在建筑下方"。

**验证**：PIL 前视比例合成图（`_tmp/fp_fire_preview.png`，含地板格+footprint 黄框）对比——1.4/偏移0 明显溢出基座；0.8~0.9 贴合炉膛。

**修法**：`fireSize` 1.4 → **0.9**，补 `offset=(0,0.1,0)` 让火焰略上抬、底部坐炉膛地面。电动版本无明火（TempControl），不动。

## Bug 2：小人卡在原地无法动 —— 疑似 PF OnGUI 异常，另一任务处理中

**新线索**：用户另报的"小人卡住"，游戏日志出现**每帧 OnGUI 异常**（`ProcessorFramework` 的 JIT `MissingFieldException`）。此类异常打断输入处理，玩家侧表现即"小人卡在原地无法动"——**很可能是真因，而非寻路/通行性**。该错误已派给熟悉 PF DLL 的独立任务排查，本任务**不碰 PF / 小人移动问题**，避免两任务改同一批文件撞车。

**本任务曾做的误诊改动已回退**：一度按"移植把 `Building_Heater` 写成 `Impassable`"推断，把两版壁炉 `passability Impassable→PassThroughOnly`+`pathCost40`+`fill1.0→0.4`。经新线索判定为误诊（卡住源于 OnGUI 异常打断输入，非堵路），**已全部回退**，两版恢复 `Impassable`/`fill 1.0`/无 `pathCost`。教训：遇"小人卡住"先查 `Player.log` 的 GUI 异常再查寻路/堵路，别先动 def。
