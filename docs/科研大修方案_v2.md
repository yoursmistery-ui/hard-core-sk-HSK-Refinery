## 四、科研进度功能重构(核心)

### 4.1 蓝图双形态

| 形态 | 物品 | 机制 | 科研值 | 定位 |
|---|---|---|---|---|
| **蓝图**(保留) | ResourceBase,直接使用 | 右键使用: 前置满足→加科研进度/累计解锁;已研究→存银行 | tier 基准(250~1000) | 快速通道、商人/掉落/事件直达 |
| **图纸书**(新增,重点) | **BookBase + CompProperties_Book + `BookOutcomeProperties_GainResearchDefinable`** | **放入书架→小人阅读**(原版读书 Job)→每读完一次推进对应研究进度(可按品质/次数) | 同 tier 或略高(阅读仪式感) | 沉浸通道、任务站点主要产出 |

- 图纸书与蓝图**一一对应同一门控研究**(同一 targetTech),两种形态二选一推进同一计数(`unlockCount` 共用)。
- 阅读推进与"使用蓝图"走同一 `BlueprintUnlockTracker`(useCounts/unlocked),不产生第二套状态。
- 图纸书有品质(CompQuality,0~3 级,对应 MO Treatise 式 30000 work 抄写或站点产出);品质越高单次科研值越高(或阅读次数需求越少),具体数值待定(见 §九决策点)。

### 4.2 书架阅读(获取与推进的核心之一)

- **图纸书可放入书架/书柜**(工业大修提供建筑,见 §七);书架 = 存储格(filter 图纸书)+ 阅读行为触发点。
- **研究加成书架**(设施链接): 书架在科研桌旁 → ResearchSpeedFactor +5%~10%(MO 同款,`CompProperties_Facility` statOffsets + patch 注入 SimpleResearchBench/HiTechResearchBench);存有图纸书的书架加成更高(激励"摆书"而非空书架)。
- **阅读产出**: 小人读书(Intellectual/Research 工作倾向,占用研究工作),读完图纸书 → 对应研究进度 +X 且累计解锁计数;图纸书读完不消失(知识保留)或可重复读(每次 +X 但递减),待定(见决策点)。
- **图书馆房间**: 借鉴 MO 的 Library 房间角色(ReadingBonus),图纸书在书房阅读科研值加成。

### 4.3 任务闭环(获取渠道的核心之二,借鉴 MO 探索桌)

```
[基地] 建造「科研任务桌」(研究 DankPyon_Exploration 式科研任务研究)
   │
   ├─ 投入「图纸残页」(TornNote 式双职能货币,商人/掉落/事件可获)
   │     (Research 工作类型小人操作,CompScanner 累计工时,烧 1 张便条)
   │
   ├─ 按「科研桌链接设施」解锁任务档位(借鉴 MO requiredLinkable):
   │     1 级: 基础桌即可(考古遗址/藏宝处)
   │     2 级: +文献柜(档案架)×3 或 先贤雕像
   │     3 级: +先贤宝珠/古基座 ×5
   │
   ├─ 生成世界任务(原版 QuestScriptDef 模板):
   │     考古遗址(废墟,搜刮图纸书/蓝图/便条)
   │     蓝图护送/图纸回收(清剿据点,营地战利品含图纸书)
   │     学者求书(交付图纸书换科研点/好感)
   │
   ├─ 远征站点 → 搜刮(战利品容器: 图纸书/蓝图/图纸残页/科研点)
   │
   └─ 回报: 图纸书带回 → 放书架阅读 → 科研进度推进
           便条回炉 → 开新任务(循环闭环)
```

- 任务档位与"设施数量/种类"绑定(软解锁,非硬 researchPrerequisites),借鉴 MO 的 `requiredLinkable/LinkablesNeeded` 设计——让基地建设参与科研推进。
- 站点战利品用**原版可搜刮容器**(或自写轻量 `Building_Lootable`,见决策点),不引 KCSG;站点地图可简化为预置模板 + 原版 GenStep。
- 卡节点动态提权(BlueprintStuckMonitor)对任务产出同样生效: 卡住哪个门控 → 任务/站点更易出对应图纸书。

### 4.4 科研进度银行(保留)

- 上限 500/1000/2000/4000/8000 动态扩容不变;蓝图与图纸书的科研值统一入账。
- 空间不足时**图纸书阅读仍推进计数但不入账**(阅读优先,银行只是溢出保护),体验优于"空间不足拒绝使用"。
