# 汉化与贴图铁律(HSK 整合)

> 来源: AGENTS.md §3 关键坑 + §3 异种人贴图机制。汉化/贴图错在 HSK 下常**静默失效**(无报错却中文不显示),务必逐条核对。

## 1. 汉化文件夹名(致命)
- 汉化文件夹必须命名为 **`ChineseSimplified (简体中文)`**(带后缀空格+括号),否则 `Languages` 不加载。
- 已批量改名 Mods 目录 95 个无后缀 `ChineseSimplified` 文件夹 + 删 2 重复副本。新增 mod 汉化时务必用正确后缀。

## 2. DefInjected 结构铁律
- 翻译文件**根节点必须 `<LanguageData>`**;**defName 作节点名**:
  - 正确: `<ThingDef><X><label>..</label></X></ThingDef>`
  - 错误: `<Defs>` + `<defName>值</defName>`(Def 定义式)→ **静默跳过、日志无报错**。
- 所有翻译 key 必须是 defName 路径,不能是自由文本。

## 3. DefInjected 全不加载的排查与兜底
- 先按 §6(该语言目录是否真被加载)+ §8(类型目录名是否等于 def 真实类名)定位——2026-08-27 全量排查发现"整包汉化无视"的**两大真因**就是这两条(金鼠族 941 键、美狐根 Languages 27 条),并非格式问题。
- 两者都排除后仍不生效,才用**兜底方案 = 把中文 label/description 直接注入 Defs 文件**(脚本 `_tmp/酒馆汉化修复/inject_labels.py`: 文本级替换具体 Def 自身节点、跳过玩家不可见道具、保留 DefInjected 不冲突),100% 生效。
- 本地整合 mod(无多语言分享需求)汉化失效时优先走此方案。

## 4. About.xml / description
- **不能含未转义 `<tag>`**(整 mod 被静默移出 ModsConfig)。
- 写完用 `ET.parse` 验证 XML 合法性。

## 5. 贴图方向命名(异种人耳/尾)
- 机制A(Biotech renderNodeProperties)渲染的耳朵贴图需 `_east/_north/_south/_west` 四方向;特殊异种耳贴图原缺 `_west`(机制B 下无此需),改走机制A后**必须补全**。
- 耳朵 `_west` = `_east` 水平镜像(实测 `RK_Texture_EarLeft_west` 与 east 镜像平均每通道差值 1.4)。
- 尾巴无 `_west` 是正常(原版 `RK_Texture_Tail` 也只有 e/n/s)。
- Vile 贴图还原流程见 `docs/04_材料与产业线/Vile贴图还原流程.md`(含 `Vile贴图重构/restore.py` 151 张自定义贴图重放)。

## 6. 加载根 = LoadFolders 的真实语义(2026-08-27 反编译定论)
`ModContentPack.InitLoadFolders`:
- 有 `LoadFolders.xml` 且命中版本节(取 ≤ 当前版本的最高节)→ **只加载该节声明的目录,根目录不加载**(除非写了 `<li>/</li>`)。
  实例: `美狐HSK拓展` 未声明根 → 根 `Languages/` 下 27 条中文是死内容,须并入已加载的 `HSK/Languages/…`。
- **没有** `LoadFolders.xml` → 自动加载 `<root>/<当前版本>`(如 `1.6/`)+ `Common/` + `<root>`。
  实例: `1.6HSK核心汉化` 无 LoadFolders,靠这条才加载 `1.6/Languages`;旧扫描漏了它→虚报 ~150 条"漏译"。
- 优先级: `</li>`(根)最后声明/自动回退时 root 最高;附属包 `1.4/xxx` 这类**无斜杠**条目也算子目录。
- 静态扫描必须复刻上面两条分支,否则漏译统计大面积失真(工具链 `_tmp/transl_scan/scan7.py`)。

## 7. Unified 缓存不能当"已译"判据
`Mods/Unified.xml` 与 `MissileGirl/Cache/Unified.xml` 都在**翻译注入之前**导出,只有被 mod 自己改写 label 的少数 def 显中文。
判"是否已译"唯一依据:**已加载中文语言根里是否存在该键**(顶层 `defName.field`,嵌套 `defName.stages.0.label`)。

## 8. DefInjected 目录名 = def 真实类名(含命名空间)
- `AlienRace.AlienBackstoryDef` 放 `DefInjected/BackstoryDef/` → **一条都不生效**(金鼠族 941 键踩过)。
- 自定义类型若继承自原版类且**注册进原版 DefDatabase**(`SeedsPlease.SeedDef`、`CombatExtended.AmmoSetDef`)→ 放**原版类名目录**(如 `ThingDef/`)是有效的,别误判成错目录。
- 列表型字段支持索引键 `defName.stages.0.label`(索引 = 同名 `li` 序号),是补 nested 缺口的正规写法。
- 生成补译文件时**同文件禁止重复键**(旧 `writeback.py` 每键写两遍,已改)。

## 9. 验证
- 汉化是否生效以**游戏内实测**(角色创建/发型列表/工作页签)为准;`Player.log` 里 `Found no <Type> named <defName> to match <key>` 是"放错类型目录"的直接证据。
- 静态复核入口:`python _tmp/transl_scan/verify_zh.py`(真缺 + 伪翻译)、`post_check.py`(编码/根节点/重复键/目录类型/hash 同步)、`gaps2.py`(嵌套待办 `work/gaps2.tsv`)。
