# 美狐HSK拓展 汉化术语表与翻译规范（所有翻译子任务必读）

## 一、铁律（违反即返工）
1. **占位符原样保留**，一个字符都不能改：`{PAWN_pronoun}` `{PAWN_possessive}` `{PAWN_nameDef}` `{PAWN_objective}`
   `[PAWN_nameDef]` `{0}` `{1}` `{BASETEXT}` `{BASELABEL}` `[Mihotownend]` `[empire]` `[TerrainFeature]` `[topicalnoun]`
   `[Community]` `[concept_positive]` `[nearnameinitial]` `[MihoWeird]` `[ofThing]` `[Color]` `[Character]` 等所有中括号/花括号变量。
   中文里把它们当英文代词用即可，例：`[PAWN_nameDef]는 태어났다` → `[PAWN_nameDef]出生在……`。
2. **换行符 `\n` 是字面的反斜杠+n**，必须成对原样保留（如 `……近战。\n\n口径：9x19mm Para`）。不得改成真实换行，不得删除。
3. **XML 转义**：译文里不要出现裸 `&` `<` `>`（需要时用 `＆`、`《》`、`〉`或改写句子）。`&amp;` 保持 `&amp;`。
4. **不许留英文整句**。唯一可保留原文的：口径代号（`9x19mm Para`/`.303 British`/`5.56x45mm`/`12 Gauge`）、
   型号代号（`FMJ`/`AP`/`HE`/`EMP` 已给出中文的除外）、以及英文人名/地名的原文括注（可不括注）。
5. **不要发明信息**：英文没说的不要加；英文写 `!!!` 就保留感叹号语气。
6. 长度：`label`/`title`/`titleShort` 尽量 ≤12 字，不加句号；`description` 用完整中文句子，句末加 `。`。
7. 输出只写译文本身，不要加引号、前缀、注释、`EN:` 之类。
8. **旧译不可信**：旧译是词表替换产物（例：`nail`→`n人工智能l`、`Miho Infantry Rifle`→`美狐 步兵 步枪`），
   仅作参考，凡有拼接痕迹一律重译。

## 二、语气与风格
- 简体中文游戏 UI 风格，参考环世界官方汉化：客观、简洁、不过度文学化。
- 种族自称/口吻句（引号内的角色台词）可以俏皮一些，例：`"I'll leave it to your imagination what happened."` → `"发生了什么就交给你想象了。"`
- 引号统一用中文双引号 `“”`。
- `Miho` 一律译 **美狐**（种族名）。`Miho, the celestial fox` → **美狐·天界之狐**。
- 形容词性 `Fox` 在 flavour 里译 **狐**（如 Fox Law → 狐之律法），动物本义译 **狐狸**。

## 四、命名词库（rulePack.rulesStrings）专用规则
格式固定为 `变量名->内容`，**`->` 左侧与 `变量名`、`[...]` 引用一律保持英文原样**，只翻译右侧内容：
- `all->fox` → `all->狐狸`
- `r_deityType->[adj]god` → `r_deityType->[adj]之神`（注意把 `[adj]` 原样放前面）
- `r_ideoName->Mihoic Code of Law` → `r_ideoName->美狐法典`
- 人名（`MihoName->Ahri`、`MihoSurname->...`）是韩语罗马音，**用中文音译**：
  `Ahri->阿狸`、`Uri->悠里`、`Yeon->延`、`Seul->瑟`、`Haneul->韩瑟尔`；
  两音节的用 2~3 个汉字，避免生僻字，读起来像人名即可。
- 若右侧本身只是变量引用（如 `cultureLeaderTitle->[cultureLeaderAdjective] [cultureLeaderNoun]`），**原样照抄**。

## 五、背景故事（AlienBackstoryDef）专用规则
- `title` = 成年身份（如 `colony fox` → 殖民地狐狸）；`titleShort` = 短形式（殖民地狐）。
- `description` 常以 `[PAWN_nameDef]` 开头，注意保留 `[PAWN_possessive]`/`{PAWN_pronoun}`。
- 韩语残留（`baseDesc` 之类）不在翻译范围内，忽略。
- 性别专用文案（female/male）分别按“她/他”处理。
