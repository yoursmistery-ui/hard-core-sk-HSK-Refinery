# 开局剧本整合·修整方案（HSK 逻辑对齐）

> 数据源：`Unified.xml`（2026-08-28 终态）+ `派系与文化总盘点.md`。逐条用脚本核了派系/物品/科研引用（`_tmp/check_scenarios.py`）。
> 判定基准 = **四要素自洽**：`开局内容 ↔ 玩家派系 ↔ 允许文化 ↔ 科技档`；外加引用有效性与文案规范。
> 本文件是**方案（待拍板后执行）**，暂不改游戏文件。

## 一、先厘清两类"看着像问题、其实不用改"

- **物品科技档 > 派系科技档**（如部落带 `MeleeWeapon_Knife`、Rich Explorer 带 `MedicineUltratech`、血族/美狐带 ultratech）：这是原版/RimWorld **刻意设计**（低科技派系给少量高级物资本就是卖点），**不动**。校验脚本会误报一片，全部忽略。
- **`Seedwheat` / `Seed_Potato`**：是 SeedsPlease 的 `SeedDef`（不是 ThingDef），**引用有效**，勿删。

真正要处理的是**引用失效**、**派系/文化/科技档错位**、**文案不合规**三类。

## 三、整合后的目标格局（"大整合"骨架）

让玩家开局按 **种族线 × 科技梯度** 成体系，而不是散蹭 `PlayerColony`：

- **人类线**：Crashlanded(Industrial) ····· 独狼 / 酒馆老板（拟 **Medieval 人类边疆**，新派系）
- **鼠族·王国线**：新开端 `RK_PlayerFaction`(Medieval) / 逃生者 / 流亡社群（Medieval）→ 意外放逐 / 鼠邦商路（`RK_PlayerExoticFaction` Industrial·国风）
- **污鼠·街头线**：家里蹲 → `Rakinia_Waster`(Industrial·街头)
- **金鸢尾线**：新旅者 / 新船组（Spacer）（上游）
- **美狐 / 雪鼠线**：特有，维持上游

核心原则：**每个非人类的自研开局，都用它所属种族的玩家派系**（自带正确异种池 + 文化 + 科技档），不再借用人类 `PlayerColony`。

## 四、文案规范（沿用你的偏好）

- 标题 = 动词+的+名词；正文 = 先…然后…接着…（三动作三物件）+ 一句处境；禁比喻升华、破折号警句、"不是 X 而是 Y"。
- 每处 ≥2 套变体防重复；开场白与正文同变体成对。
- 家里蹲现在**直接中文化重写**（原英文私梗不保留）。
