3 踩到的坑 务必记住

Kiln（陶瓷窑）不能挂普通 RecipeDef。Core_SK 把它声明成 UniversalFermenterSK.ThingDef_UF，任何普通配方挂上去，冷启动会逐条刷：

RecipeDef 'RK_Met_MakeMoldHandaxe' should have Class="UniversalFermenterSK.RecipeDef_UF"
because this recipe uses by ThingDef_UF Kiln.

Vile 自己的窑配方不报，是因为它们是 ProcessorFramework 的 ProcessDef。制模因此改挂 PotteryStation（陶工台）——语义也更对，捏模子本来就是陶工活。

→ 往 HSK 的生产建筑挂新配方前，先确认该建筑有没有被 UF 接管（查 Core_SK 的 RecipeDefs_UF 与 ThingDef_UF）。
