## 2. RimWorld 贴图机制（反编译定论 · 高价值）

用 `ilspycmd` 反编译 `RimWorldWin64_Data/Managed/Assembly-CSharp.dll`：

```bash
cd _tmp/ilspy/ilspycmd_pkg/tools/net10.0/any
dotnet ilspycmd.dll -t Verse.Graphic_Multi <dll>
dotnet ilspycmd.dll -t Verse.Graphic            # MeshAt
dotnet ilspycmd.dll -t Verse.Graphic_Collection  # 堆叠图标
```

### ① 东西向 drawSize 自动交换
`Graphic.MeshAt`：`if (rot.IsHorizontal && !ShouldDrawRotated) vector = drawSize.Rotated()`
→ **东西朝向自动交换 drawSize 的 x/y**，贴图内容**无需预旋转**，只要给竖版画布的侧视图即可。

### ② Graphic_Multi 缺文件 fallback 链
`north` 缺 → 用 `south`（+180°）；`east` 缺 → 用 `west` 镜像；`west` 缺 → 用 `east` 镜像（走 `MeshPool.GridPlaneFlip`）；全缺 → 用 base path。

### ③ 堆叠图标 = 文件夹
`Graphic_Collection.Init`：`ContentFinder.GetAllInFolder(req.path)` **按文件名排序**成子图数组。
`Graphic_StackCount.SubGraphicForStackCount`：1 件→`subGraphics[0]`；满栈→最后一个；其余按数量比例取中间档。
→ 堆叠图标必须建成**文件夹 + `_a/_b/_c`** 三档（污染统一的 Asphalt 已是此规范）。

## 3. 用户拍板的切图规则

### 通用四向规则（水平储罐）
- **S** = 水平正面（带品牌/阀门标志的那面）
- **N** = **S 的左右镜像**（用户先说"N 不做同 S"，后改为镜像）
- **E** = 从源图**指定位置**取图，转 90° 成竖版
- **W** = **E 的镜像**

⚠️ **关键：每座储罐的 NS / EW 取图位置各不相同，不能套用统一象限**——见下表。
