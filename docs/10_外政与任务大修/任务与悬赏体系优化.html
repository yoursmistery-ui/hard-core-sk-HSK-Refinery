任务与悬赏体系优化

立档 2026-09-02。性质：设计方案，未实现。把现有 任务大修HSK 八期（RimQuest 任务板 + SimpleWarrants 通缉 + 自研 QuestBoardHSK.dll）按等级/奖励/来源/属性四维度重构，并与外政（双线认可度/从属/阵营线）、刺客两派（库林中世纪 + 美狐高科技）、天网 raid-boss、战争委任打通。= 主方案 §四 + §五 P3 的展开。 原则：复用现成能力、表驱动、全主线程落（好感/发信/起任务/Dialog）、别加功能型 mod。挂钩类名见 外政数据结构与挂钩点附录.md §5；线程约束见 外政核心_线程与事件决策模型.md。

一、任务分级 tier（补现缺的一等概念）

已建成一等表 TaskTierDef（1.6/Defs/TaskTier/RK_TaskTiers.xml，改值/加档不重编；BountyRules.TierOf/TierRewardMult 优先查表、缺则回退内置）。rank 1–4 按目标科技档落位、rank 5=天网终章 boss（非通缉）：

tier 定位 威胁点带 目标科技档 rewardMult 可发来源
T1 地方 寻物/驯捕/低阶通缉 150–350 Neolithic–Medieval 1.0 SW 随机、商队夹带、面对面
T2 领地 清剿据点/族色委托 350–700 Industrial 1.3 族色发单、玩家发布
T3 外政 定向暗杀(失败不扣好感)/勒索 700–1400 Spacer 1.7 公会直供/NPC patron、认可度/tension 解锁
T4 战争 战争委任 / 区域大 boss 1400+ Ultra–Archotech 2.2 读 BOTR ActiveWars
T5 终章 天网 Skynet 最终 boss 5000+ 机器族(非通缉) 3.0 天网 boss 战令专章（不入公告牌）

落地：tier 由目标科技档派生（不入库、不给 Warrant 加字段）；发单窗/交付回写/暗杀源/#8 奖励统一读此表，UI 徽章 T{rank} 按 badgeColor 上色。#1 显式分层已接：BountyRadioManager.warrantTier(loadID→rank, 存档) 覆盖派生值——暗杀源钉 T3、#8 优先读覆盖、SetWarrantTier 供天网 T5 战令等未来钉档；未钉则按科技档派生。每档带 badgeColor/summary/failGoodwill 供 UI 与结算后续取用（现 failGoodwill 全 0=不扣，契合暗杀规则）。

二、奖励统一公式（表驱动，单一金额源）

现双路径未统一（悬赏=SW AssignRewards 公式；族色=XML×1.75）。合并为读一张 RewardCurveDef 表：

银币 = Base(tier) × 科技档系数(低档×0.5) × 派系关系倍率(0→1.0/+100→1.5/−100→1.4)
       × 从属修正(帝国从属间发单 ×0.6) × 双线认可增益(对应线 standing 越高 ×1.0~1.3)
  • 改 HarmonyPatches.cs 补 #8 WarrantsManager.AssignRewards Postfix 读表（替 BountyRules 里的散常数）。
  • 实物包 BountyRewards.cs 选池改按 tier × 目标派系阵营线（imperial 池 / free 池 / 各族特产）。
  • 保留：SW 30% 尸体酬概率、财富缩放、受雇成功率科技线性。
  • 预付手续费：从"目标科技档 500~5000"改 tier × 目标科技档；帝国从属间发单免/减预付。
  • 发单金额系统给、玩家不手填：Dialog_IssueWarrantHSK 去掉"输入赏金"字段，只做"选目标 → 显示系统报价 → 确认"；通缉/暗杀单赏金一律按上面公式算，预付同理自动定。

三、来源体系（注册表 + tier 门控）

现 5 源全保留（SW 周期随机 / 开局补单封顶 / 商队夹带 25% / RimQuest 面对面 / 玩家发布）。新增外政驱动定向任务：

  1. 双线认可度解锁：某线 standing 达阈 → 解锁该线专属定向任务（帝国线给护商/讨伐、free 线给走私/佣兵单）。
  2. 战争委任：读 BOTR ActiveWars/TerritorialMissionType → 生成 T4 战令（复用现成 TerritorialMissions）。
  3. 天网 raid-boss：T4 定向战令（见 天网Skynet_boss整合.md §3）。
  4. 刺客两派委托：库林隐修会发 Medieval 档、美狐机枢会发 Spacer/骇入档（见 刺客派系双阶整合.md）。

门控：低科技/低认可刷不出高档单。B 决策核心抛 command → C 订阅注册来源 → 主线程 QuestUtility.CreateQuest 落地（不后台跑）。

四、任务属性 × 外政联动

每任务挂外政上下文：归属派系 · 阵营线(imperial/free) · 目标从属态 · 认可度收益(±) · 好感代价 · tier。 落地：新增 QuestTagDef + loadID→上下文 字典（存档 Scribe；Warrant 不加字段）。 - 完成 → 回写双线认可度（按任务阵营线给对应 standing + 分项，附录 §1）与好感（原版 TryAffectGoodwillWith）。 - 失败/弃单 → 沿用八期故事信变体（Tale_TakeFail_*）+ 好感结算；暗杀链例外：失败不扣好感、成功加好感（见 §五）。

五、悬赏令专项优化（公告牌 / 无线电 / 通缉）

  • 目标合法性叠加阵营线/从属：现有 IsWorldNpcFaction+TechGapOk → 再叠"阵营线/从属"过滤：帝国从属间不得互开悬赏；同线目标降好感代价、跨线提价。
  • 海报卡增行：阵营线 / 目标从属态 / 本单认可收益 / 暗杀解锁阈值。
  • 暗杀战令（好感/敌对驱动，无间谍网）：目标线认可过低 或 BOTR FactionBorderContact.tension 超阈 → 解锁暗杀 ChoiceLetter；接现通缉 4 类 QuestScriptDef（Pawn/Animal/Tame/Artifact）扩"暗杀"子类，走原版 Pawn.Kill/SetRelationDirect（避开 BOTR 占的 CheckDefeated/Quest.Accept）。结算：成功→加好感、失败→不扣好感（覆盖 SW 原拒付 −100/发单激怒，暗杀链不扣）；赏金金额系统按 §二 公式定、玩家不手填。
  • 保留：无线电待接收队列、全局一周一条限流、榜上 15 天期限、≤2 天红字警示。
