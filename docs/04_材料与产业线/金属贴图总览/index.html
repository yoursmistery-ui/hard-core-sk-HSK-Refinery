配套册

本册只收金属链;全体系材料的六档归属(原始/中世纪/电力/石化/太空/极致 × 家族:锻造金属·辅助金属·塑料·合成纤维·玻璃·陶瓷·宝石)见 材料六档分类。

分组判定依据

  • 金属与合金(可塑材料) — stuffProps 里含 Metallic/StrongMetallic/RuggedMetallic/… —— 能在工作台/建筑里当材质选用;组内按"能顶替到哪档金属"排(36)
  • 贵重品·提纯料（不作材质） — HSK 官方把它归在 Extracted/Metals/PRS(贵重品) 或 Metallic/RARBar 但材质覆盖≤2 的提纯金属——宝石·化石·未加工贵金属·纯铬纯钴纯镍纯钨钒锰钼锌焊锡等,只作收藏/贸易/配方原料与合金添加剂,**不参与能力档阶梯评价**(标 V 级)(21)
  • 冶金中间产物 — HSK thingCategory = Metallurgical + 本地自建炉渣:冶铁/炼钢链的半成品(5)
  • 金属矿石/精料 — ResourcesRaw/Extracted/Metals 下各档矿石(含天然金银、海绵铁)(12)
  • 工程材料·聚合物与复合(按能替代哪档金属排) — 聚合物/复合/超硬材料,不是冶金产物但挂在同一条分类树下。本组按"能把哪档金属顶替掉"分四档(超钢级 > 代钢级 > 强化工程级 > 塑料级),每档写明能做什么、做不了什么、以及比同档金属多出的独家用途(12)
  • 参考:宝石/石料 — 与金属同用 Precious/Metallic 分类的宝石与石材,对照用(1)

怎么用

卡片贴图区从左到右就是时间顺序:① 起点(该 def 自己 mod 的 Defs 写的值)→ ②③ 中间被哪个 mod 的哪个补丁文件换成什么(紫框=Vile 专用图那一版,即"Vile 本来长这样")→ 最后一列绿框=生效(终态),也就是游戏里实际那张;段标题末尾的 ← 补丁文件名 指出是谁改的。只有一列的金属没被动过。StackCount 的 a/b/c 叠放变体每段都列。 本地补丁×N 悬浮显示补丁文件名,便于回 Patches/ 继续改。全量链表 → 附注① 贴图链;缺项与本地改动 → 附注②。
